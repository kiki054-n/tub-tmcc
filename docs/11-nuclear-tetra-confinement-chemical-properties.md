# S, P, O の特殊性と核内テトラ拘束構造の関連

> 第2周期（N, O）と第3周期（P, S）の化学的な特殊性（結合角・混成の違い）が、根源的に核内の陽子・中性子のテトラ拘束構造の違いによって決定されることを論じる
> 草案 v0.1 / 2026-11-07

---

## 核心主張

S, P, O の化学的な特殊性（結合角・s-p 混成の違い）は、根源的に **核内の陽子・中性子のテトラ拘束構造の違い** によって決定される。

- **核の大きさ** → 電子殻の距離・格子線エネルギー場の対称性を決定
- **内殻の遮蔽** → 価電子の格子線エネルギー密度を変化させる
- **s-p 格子線エネルギー差** → 混成の抑制・促進を決定
- **F_R 強度（k）** → 結合角の縮小・拡大を決定

## 2. 核内テトラ拘束と電子殻の対応

TTTの観点では、原子核は陽子・中性子のテトラ拘束構造を持つ。核子が四面体配置で拘束されると、内向きの力が中和し、外向きの電子を引きつける「格子線エネルギー場」が形成される。

```
核の構造が電子殻に与える影響：

┌─────────────────────────────────────────────────────────────┐
│  核（テトラ拘束） → 格子線エネルギー場 → 電子殻の形成        │
│                                                             │
│  ・陽子数 Z → 正電荷の総量 → 電子の数を決定                 │
│  ・中性数 N → 核の拘束強度 → 格子線エネルギー密度を決定    │
│  ・核の大きさ → 電子殻の距離 → 軌道エネルギーを決定          │
└─────────────────────────────────────────────────────────────┘
```

## 3. O（第2周期） vs S（第3周期）の比較

### 酸素 O-16

- 陽子 8 + 中性子 8 = 核子 16
- K殻（1s²）+ L殻（2s²2p⁴）
- **核が小さい** → 価電子（L殻）が核に近い
- 格子線エネルギー密度が高い → 孤電子対が強く局在
- F_R 強度：孤電子対の斥力が大きい（k ≈ 1.26）
- 結果：H-O-H = 104.5°（四面体角 109.5° から大きく縮小）

### 硫黄 S-32

- 陽子 16 + 中性子 16 = 核子 32
- K殻 + L殻 + M殻（3s²3p⁴）
- **核が大きい** → 価電子（M殻）が核から遠い
- 内殻（K, L）が遮蔽効果を持つ → 価電子の格子線エネルギー密度が低下
- F_R 強度：孤電子対の斥力が相対的に小さい（k ≈ 2.39、ただ距離が大きいため実効的な斥力は小さい）
- 結果：H-S-H = 92.1°（p軌道の直交角 90° に近い）

## 4. N（第2周期） vs P（第3周期）の比較

### 窒素 N-14

- 陽子 7 + 中性子 7 = 核子 14
- K殻 + L殻（2s²2p³）
- **核が小さい** → 価電子が核に近い
- 格子線エネルギー密度が高い → 孤電子対が強く局在
- F_R 強度：k ≈ 1.24
- 結果：H-N-H = 107.0°（四面体角からわずかに縮小）

### リン P-31

- 陽子 15 + 中性子 16 = 核子 31
- K殻 + L殻 + M殻（3s²3p³）
- **核が大きい** → 価電子が核から遠い
- 内殻の遮蔽 → 価電子の格子線エネルギー密度が低下
- 3s軌道と3p軌道の格子線エネルギー差が大きい → s-p 混成が抑制
- F_R モデルでは k ≈ 4.72 と異常値（単純な斥力モデルでは記述困難）
- 結果：H-P-H = 93.5°（p軌道直交角 90° に非常に近い）

## 5. 核格子配置と s-p 混成の関係

### s-p 混成のTTT的解釈

現代化学では「sp³ 混成」で説明するが、TTTでは：

```
s軌道とp軌道の格子線エネルギーが近い → 混成が起きやすい
s軌道とp軌道の格子線エネルギー差が大きい → 混成が抑制される
```

核格子配置がこのエネルギー差を決定するメカニズム：

```
┌────────────────────────────────────────────────────────────┐
│  核子のテトラ拘束 → 格子線エネルギー場の対称性 →            │
│  電子殻の格子線エネルギー分布 → s-p エネルギー差            │
└────────────────────────────────────────────────────────────┘
```

**第2周期（N, O）**：
- 核が小さい → 格子線エネルギー場が強く、対称性が高い
- s軌道とp軌道の格子線エネルギー差が小さい
- → sp³ 混成が起きやすい → 四面体角に近い結合角

**第3周期（P, S）**：
- 核が大きい → 格子線エネルギー場が弱く、対称性が崩れる
- 内殻（K, L）が遮蔽効果を持つ
- s軌道とp軌道の格子線エネルギー差が大きい
- → sp³ 混成が抑制される → p軌道直交角に近い結合角

## 6. 核子数と格子線エネルギー密度の定量的関係

### 核半径の推定

核半径は R = r₀ · A^(1/3)（r₀ ≈ 1.2 fm）で推定される。

| 核種 | A | A^(1/3) | R (fm) | Z/A | Z/R³（格子線エネルギー密度の指標） |
|-----|---|---------|--------|-----|--------------------------------|
| N-14 | 14 | 2.410 | 2.89 | 0.500 | 0.289 |
| O-16 | 16 | 2.520 | 3.02 | 0.500 | 0.289 |
| P-31 | 31 | 3.141 | 3.77 | 0.484 | 0.280 |
| S-32 | 32 | 3.175 | 3.81 | 0.500 | 0.289 |

Z/R³ は「単位体積あたりの陽子数」を指標とした簡易的な格子線エネルギー密度の推定値である。第2周期（N, O）と第3周期（P, S）で核半径に大きな差がある。この差が価電子殻の格子線エネルギー密度に反映され、s-p 混成の抑制・促進を決定する可能性がある。

## 7. 結論：S, P, O の特殊性の根源

S, P, O の化学的な特殊性（結合角・混成の違い）は、以下の連鎖として理解できる：

```
┌─────────────────────────────────────────────────────────────┐
│  ① 核内の陽子・中性子のテトラ拘束構造                      │
│     → 核の大きさ・対称性・格子線エネルギー場を決定          │
│            ↓                                                │
│  ② 電子殻の形成（K, L, M殻）                                │
│     → 核の格子線エネルギー場に応じた軌道エネルギー分布      │
│            ↓                                                │
│  ③ s軌道とp軌道の格子線エネルギー差                         │
│     → 第2周期：差が小さい（混成しやすい）                   │
│     → 第3周期：差が大きい（混成が抑制）                     │
│            ↓                                                │
│  ④ 孤電子対のF_R強度（k）と結合角                           │
│     → O, N：k ≈ 1.25、四面体角から縮小                    │
│     → S：k ≈ 2.39、距離増大で実効斥力減少                 │
│     → P：k ≈ 4.72（異常値）、混成抑制でp軌道支配            │
└─────────────────────────────────────────────────────────────┘
```

つまり、S, P, O の化学的な特殊性（結合角・混成の違い）は、根源的には **核内の陽子・中性子のテトラ拘束構造の違い**（核の大きさ・内殻の遮蔽・格子線エネルギー場の対称性）によって決定される。
