## 1. 原理：符号の交互

| 要素数 | 式 | 積 | 状態 |
|---|---|---|---|
| 2 | $XY$ | $+1$ | 閉 |
| 3 | $XYZ$／$FBI$ | $-1$ | 開（相手を要する） |
| 4（3＋包む1） | $XYZ\pi$／$FBI\pi$ | $+1$ | 閉（1つのものとして成立） |
| 5 | | $-1$ | 開（再び相手を要する） |

各 $X_i=\pm1$ で積が $(-1)^n$ になる点は $2^{n-1}$ 個（半超立方体 $D_n$）。$n=3$ の4点は正四面体で、頂点の和は0。

π の読み（Claude の解釈、検討中）：$XYZ=-1$ に掛けて $+1$ にするので、π は $-1$ の働きをする。半回転 $e^{i\pi}=-1$ と一致する。

## 2. 電子：電子数の偶奇

| 分子 | 電子数 | 偶奇 | 不対電子 |
|---|---|---|---|
| H₂ | 2 | 偶 | 0 |
| N₂ | 14 | 偶 | 0 |
| H₂O | 10 | 偶 | 0 |
| CO₂ | 22 | 偶 | 0 |
| CH₄ | 10 | 偶 | 0 |
| **O₂** | **16** | **偶** | **2（三重項）** |
| OH | 9 | 奇 | 1 |
| CH₃ | 9 | 奇 | 1 |
| NO | 15 | 奇 | 1 |
| NO₂ | 23 | 奇 | 1 |
| ClO₂ | 33 | 奇 | 1 |

- 奇数側：電子が奇数個なら、必ず1個以上が対になれない。規則と合うが、数え方から必然なので**検証にはならない**。
- 偶数側：多くは閉じるが、**O₂ は偶数なのに開いている**。「偶数なら閉じる」は電子では成り立たない場合がある。
- 読みの候補（未決）：O₂ は「数」では閉じているが「向き」では閉じていない。2本の軌道が直交して2方向に分かれ、それぞれに1個ずつ入る。docs/26 §5 の「酸素は4方向の偏り」との関係を調べる必要がある。

### 2.1 O₂ は双錐（本人、2026-11-09 01:56〜01:58）

**主張（本人）**：O₂ は双錐だから開いている。3角双錐か5角双錐、または**3角と5角の両方が重なっている**形もありうる。

**docs/26 との対応**

| docs/26 の結果 | O₂ |
|---|---|
| F（向きの和）は双錐でも0 | 電子16個（偶数）で、数としては閉じている |
| BI の回転は双錐では主軸のまわりに残りうる | 対にならない電子2個 |
| 残るのは回転が一方の向きを選び、鏡映で反転しないときだけ | 2個のスピンが同じ向き（三重項）。磁石に引き寄せられる（常磁性） |

→ O₂ は「数では閉じ、回転では開いている」。反例ではなく、双錐の性質として読める。

**4角は除かれる**：4角双錐は正8面体（プラトン立体）で、BI の回転が打ち消し合う。O₂ が回転を残すなら 3角・5角（またはその重なり）になり、本人の主張と矛盾しない。

**3角と5角の重なり**（共通の軸と2つの極を共有する場合の数、Claude による数え上げ）

| | 3角双錐 | 5角双錐 | 重ね合わせ |
|---|---|---|---|
| 頂点 | 5 | 7 | 2＋3＋5＝**10** |
| 赤道の点 | 3 | 5 | **8** |
| 辺 | 9 | 15 | 24 |
| 要素数 2E | 18 | 30 | **48** |

- 赤道の点 8 は酸素の陽子数（電子数）8 と同じ。頂点 10 は「誕生の10」（docs/26 §11）と同じ。どちらも**数の一致を記録するだけ**で、理由はまだ示せていない。
- 3 と 5 は互いに素なので、重ねた形が軸のまわりで自分と重なる回転は1周（360°）だけになる。回転の向きが偏りやすい形と言えるが、軸を含む鏡映面が残るかどうかは、3角と5角の向きのそろえ方で変わる（未検討）。

**次の照合**

- B₂（電子10個）・S₂（電子32個）も、偶数なのに三重項で常磁性。O₂ と同じ双錐で説明できるか。
- N₂（電子14個、磁性なし）は、双錐でないか、回転が打ち消し合う形のはず。

### 2.2 P も双錐（本人、2026-11-09 01:59）

**主張（本人）**：P（リン）も双錐。

**観測されている形**（標準の分子構造、VSEPR）

| 分子 | 中心 | 形 | 磁性 |
|---|---|---|---|
| PF₅・PCl₅ | P | **3角双錐**（極2＋赤道3） | なし（閉） |
| SF₄ | S | 3角双錐の赤道1つが孤立電子対（シーソー形） | なし |
| IF₇ | I | **5角双錐**（極2＋赤道5） | なし |

- P の 3角双錐は**実在する形**として確かめられている。5角双錐も IF₇ で実在する。
- PF₅ では、極（軸）の2つと赤道の3つが入れ替わる回転（**ベリー擬回転**）が起きる。双錐の形そのものが回っている。
- ただし PF₅ は磁性を持たない。**双錐の形だけでは開かない**。O₂ で回転が残るのは、docs/26 の条件（回転が一方の向きを選び、鏡映で反転しない）が満たされるときだけ、という読みと合う。
- O₂ の双錐は TTT の内部の形（本人の読み）で、PF₅ の双錐は原子の並び（観測）。同じ双錐でも数えている階層が違う。
- 次へのつながり：第3周期の P・S の結合角（docs/26 の持ち越し）は、3角双錐とその赤道の孤立電子対（SF₄）から考えられる。

## 3. 核子：陽子数 Z・中性子数 N の偶奇

天然に存在する核種（存在比 > 0）を4つに分けて数えた。

| Z-N | 核種数 | 割合 |
|---|---|---|
| 偶-偶 | 167 | 58.4% |
| 偶-奇 | 56 | 19.6% |
| 奇-偶 | 54 | 18.9% |
| 奇-奇 | 9 | 3.1% |
| 合計 | 286 | |

**奇-奇の9核種**

| 核種 | Z | N | 備考 |
|---|---|---|---|
| H-2（重水素） | 1 | 1 | 安定、Z = N |
| Li-6 | 3 | 3 | 安定、Z = N |
| B-10 | 5 | 5 | 安定、Z = N |
| N-14 | 7 | 7 | 安定、Z = N |
| K-40 | 19 | 21 | 長寿命の放射性 |
| V-50 | 23 | 27 | 長寿命の放射性 |
| La-138 | 57 | 81 | 長寿命の放射性 |
| Lu-176 | 71 | 105 | 長寿命の放射性 |
| Ta-180 | 73 | 107 | 励起状態（180m）で崩壊が観測されていない |

**読み**

- 陽子も中性子も、奇数個のままでは開いている。両方が奇数（奇-奇）だと、開いたものが2つ残るので、ほとんど存在できない。
- 存在できる軽い奇-奇（H-2・Li-6・B-10・N-14）はすべて Z = N。余った陽子1個と中性子1個が**互いの相手**になり、2つで閉じる、と読める。これは「双極で閉じる（$XY=1$）」の形。
- 重い核では Z = N で閉じる道がなくなり（中性子が多くなる）、奇-奇は不安定になる。

**正直な位置づけ**：偶-偶が多く奇-奇が少ないことは、標準の原子核物理では**対効果**（質量公式の対エネルギー項）として知られている。今回の照合は TTT の新しい予言ではなく、**既知の事実と矛盾しないかの確認**。合っている。

## 6. 鉄へ向けた照合点（2026-11-09 02:01〜02:04）

本人：「鉄までたどり着くとどうなるかな？大変だぞこれは」「温度で固溶線があるのもこのせいだろうね」「ステンレスがさびない理由も出てきそうだね」

鉄そのものは、第2周期 → 第3周期（P・S の双錐）→ K・Ca → Sc〜Fe と順に固めてから扱う。ここでは、そのとき照合する観測事実を先に置いておく。

### 6.1 鉄の三つの顔

| | 事実 | 読み |
|---|---|---|
| 原子核 | Fe-56：陽子26・中性子30（偶-偶）。核子1個あたりの質量が最も小さい核の一つで、融合でも分裂でもエネルギーを取り出せない終点 | 数として完全に閉じている |
| 電子 | 26個（偶数）だが、原子1個で不対電子4個（3d の5軌道に6個） | 数で閉じ、回転で大きく開く（O₂ の2個より多い）。d 軌道の「5」 |
| 磁性 | 金属の鉄は多数の原子の向きがそろう（強磁性、キュリー点 770°C） | 「回転が一方の向きを選ぶ」（docs/26）が集団で起きている |

**難所**：d 軌道の5つが加わる／4s と 3d で入る順番が入れ替わる／磁性が1粒子から格子全体の現象になる。

### 6.2 ヘモグロビン：開いたもの同士が閉じる

- O₂ が結合していない鉄（デオキシ）は不対電子をもち、常磁性。
- O₂ が結合すると全体が反磁性になる（オキシ、Pauling と Coryell 1936）。
- 開いた O₂ と開いた鉄が互いの相手になって閉じる。§4「開いたもの同士が相手になって閉じる」がそのまま観測に出ている。
- 鉄が6つの相手に囲まれる正8面体では、条件により不対電子が0になる（低スピン）。

### 6.3 鉄と炭素の固溶線：正8面体か双錐か

| 温度域 | 結晶 | 磁性 |
|---|---|---|
| 912°C 未満 | 体心立方（α鉄） | 770°C 未満で強磁性 |
| 912〜1394°C | 面心立方（γ鉄） | なし |
| 1394°C〜融点 | 体心立方（δ鉄） | なし |

- 磁性を入れずに計算すると、鉄は低温で体心立方にならない。α鉄が体心立方でいられるのは磁性のため、というのが固体物理の結果。開いた回転が結晶の形を決めている。

| | 炭素の最大固溶量 | 炭素が入るすき間 |
|---|---|---|
| γ鉄（面心立方） | 約 2.14%（1147°C） | 正8面体（6方向が等しい） |
| α鉄（体心立方） | 約 0.022%（727°C） | 一方向につぶれた8面体（4角双錐で、極の距離が赤道と違う） |

- 正8面体のすき間には炭素が多く入り、つぶれた双錐にはほとんど入らない。docs/26「プラトン立体は閉じて釣り合い、双錐はねじれる」と同じ形。温度で結晶が切り替わると、すき間の形も切り替わり、固溶線が折れ曲がる。
- **注意**：固溶線は磁性のない合金（アルミと銅など）にもあり、一般には温度とエントロピーで説明される。言えるのは「鉄と炭素では、磁性とすき間の形が固溶線を決めている」まで。

### 6.4 ステンレスがさびない理由：3要素が8面体に包まれて閉じる

- クロムを約 10.5% 以上含むと、表面に緻密な Cr₂O₃ の膜ができ、傷ついてもすぐ張り直される（不動態）。

| | 鉄のさび | クロムの膜 |
|---|---|---|
| 膜 | すき間だらけで、ふくらんではがれる | 緻密で、すき間なくつながる |
| 金属イオンの居場所 | 酸素の8面体の中（Fe³⁺） | 酸素の8面体の中（Cr³⁺） |
| d 電子 | 5個（5軌道に1個ずつ） | 3個（低い3軌道に1個ずつ） |

- Cr³⁺ は8面体の中で低い3軌道に1個ずつ入り、3つの向きに均等に分かれて偏りが打ち消し合う。化学では反応しにくく動きにくい並びとして知られる。TTT の読みでは「3要素が8面体に包まれて、向きとして閉じている」（$FBI\pi=1$ の形）。開いた O₂ がそこへ入り込めない。
- SUS304（クロム18%・ニッケル8%）はニッケルで室温でも面心立方を保ち、磁石につかない（§6.3 の正8面体の側）。
- **注意**：さびない直接の理由はクロムの膜で、面心立方かどうかではない。体心立方で磁石につく SUS430 もさびない。

### 6.5 鉄に着いたときに答える問い

- 3d の5軌道と6個の電子から、不対電子4を TTT の数え方で出せるか。
- 磁性（集団の向きのそろい）を、1粒子の「回転の残り」から格子へどう広げるか。
- 体心立方の4角双錐のすき間と、面心立方の正8面体のすき間の違いを、docs/26 のねじれの条件で説明できるか。
- Cr³⁺ の「3つに1個ずつ」が閉じ、Fe³⁺ の「5つに1個ずつ」が閉じきらない差を、符号の交互で説明できるか。
