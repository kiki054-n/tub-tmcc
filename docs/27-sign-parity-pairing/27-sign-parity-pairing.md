## 0. 要約

1. 原理（本人）：$XYZ\pi=1$、$FBI\pi=1$。3要素を1つで包む。立体格子が1つの粒子で、双極関係。
2. 符号の交互：$XY=1$、$XYZ=-1$、$XYZ\pi=1$。要素が**奇数個で開き**（$-1$、相手を要する）、**偶数個で閉じる**（$+1$）。
3. 電子：奇数個の電子をもつ分子（OH・CH₃・NO・NO₂・ClO₂）はすべて不対電子をもつ。ただしこれは数え方から必然で、検証にはならない。検証になるのは偶数側で、**O₂ は電子16個（偶数）なのに不対電子2個**（反例）。
4. 核子：天然に存在する286核種のうち、陽子・中性子がともに偶数（偶-偶）が **167（58.4%）**、ともに奇数（奇-奇）は **9（3.1%）**。長寿命の放射性4つを除く奇-奇は **H-2・Li-6・B-10・N-14・Ta-180** の5つだけ。
5. 軽い奇-奇の4つはすべて **Z = N**。余った陽子1個と中性子1個が互いの相手になって閉じている、と読める。
6. ヘリウム4（2＋2、偶-偶）は軽い核の中で特に強く結ばれている（docs/26：1本あたり重水素の2.12倍）。

## 1. 原理：符号の交互

| 要素数 | 式 | 積 | 状態 |
|---|---|---|---|
| 2 | $XY$ | $+1$ | 閉 |
| 3 | $XYZ$／$FBI$ | $-1$ | 開（相手を要する） |
| 4（3＋包む1） | $XYZ\pi$／$FBI\pi$ | $+1$ | 閉（1つのものとして成立） |
| 5 | | $-1$ | 開（再び相手を要する） |

各 $X_i=\pm1$ で積が $(-1)^n$ になる点は $2^{n-1}$ 個（半超立方体 $D_n$）。$n=3$ の4点は正四面体で、頂点の和は0。

π の読み（Claude の解釈、検討中）：$XYZ=-1$ に掛けて $+1$ にするので、π は $-1$ の働きをする。半回転 $e^{i\pi}=-1$ と一致する。

## 2. 電子：電子数の偶奇

| 分子 | 電子数 | 偶奇 | 不対電子 |
|---|---|---|---|
| H₂ | 2 | 偶 | 0 |
| N₂ | 14 | 偶 | 0 |
| H₂O | 10 | 偶 | 0 |
| CO₂ | 22 | 偶 | 0 |
| CH₄ | 10 | 偶 | 0 |
| **O₂** | **16** | **偶** | **2（三重項）** |
| OH | 9 | 奇 | 1 |
| CH₃ | 9 | 奇 | 1 |
| NO | 15 | 奇 | 1 |
| NO₂ | 23 | 奇 | 1 |
| ClO₂ | 33 | 奇 | 1 |

- 奇数側：電子が奇数個なら、必ず1個以上が対になれない。規則と合うが、数え方から必然なので**検証にはならない**。
- 偶数側：多くは閉じるが、**O₂ は偶数なのに開いている**。「偶数なら閉じる」は電子では成り立たない場合がある。
- 読みの候補（未決）：O₂ は「数」では閉じているが「向き」では閉じていない。2本の軌道が直交して2方向に分かれ、それぞれに1個ずつ入る。docs/26 §5 の「酸素は4方向の偏り」との関係を調べる必要がある。

## 3. 核子：陽子数 Z・中性子数 N の偶奇

天然に存在する核種（存在比 > 0）を4つに分けて数えた。

| Z-N | 核種数 | 割合 |
|---|---|---|
| 偶-偶 | 167 | 58.4% |
| 偶-奇 | 56 | 19.6% |
| 奇-偶 | 54 | 18.9% |
| 奇-奇 | 9 | 3.1% |
| 合計 | 286 | |

**奇-奇の9核種**

| 核種 | Z | N | 備考 |
|---|---|---|---|
| H-2（重水素） | 1 | 1 | 安定、Z = N |
| Li-6 | 3 | 3 | 安定、Z = N |
| B-10 | 5 | 5 | 安定、Z = N |
| N-14 | 7 | 7 | 安定、Z = N |
| K-40 | 19 | 21 | 長寿命の放射性 |
| V-50 | 23 | 27 | 長寿命の放射性 |
| La-138 | 57 | 81 | 長寿命の放射性 |
| Lu-176 | 71 | 105 | 長寿命の放射性 |
| Ta-180 | 73 | 107 | 励起状態（180m）で崩壊が観測されていない |

**読み**

- 陽子も中性子も、奇数個のままでは開いている。両方が奇数（奇-奇）だと、開いたものが2つ残るので、ほとんど存在できない。
- 存在できる軽い奇-奇（H-2・Li-6・B-10・N-14）はすべて Z = N。余った陽子1個と中性子1個が**互いの相手**になり、2つで閉じる、と読める。これは「双極で閉じる（$XY=1$）」の形。
- 重い核では Z = N で閉じる道がなくなり（中性子が多くなる）、奇-奇は不安定になる。

**正直な位置づけ**：偶-偶が多く奇-奇が少ないことは、標準の原子核物理では**対効果**（質量公式の対エネルギー項）として知られている。今回の照合は TTT の新しい予言ではなく、**既知の事実と矛盾しないかの確認**。合っている。

## 4. 原理との対応

| 原理 | 電子 | 核子 |
|---|---|---|
| 奇数は開く | 不対電子（必然） | 奇-奇はほぼ不安定 |
| 偶数は閉じる | 多くは閉じる。**O₂ は反例** | 偶-偶が最多 |
| 開いたもの同士が相手になって閉じる | 共有結合（H・H → H₂） | Z = N の奇-奇（陽子1＋中性子1） |
| 4で強く閉じる | ― | ヘリウム4（2＋2） |
