# 超微細構造の異常の精密計算：核のテトラ拘束構造と電子殻の関係

> 水素・重水素原子の1s超微細分裂の理論値と実測値の差（異常）を精密に計算し、核内の陽子・中性子のテトラ拘束構造の非理想性として解釈する
> 草案 v0.1 / 2026-11-07

---

## 核心主張

超微細構造の異常（理論値と実測値の差）は、核内の陽子・中性子のテトラ拘束構造の非理想性（有限サイズ・変形・ポーラリゼビリティ）を反映している。TTTでは、この異常を「格子線エネルギー場の非対称性」として統一的に記述できる。

## 2. 水素原子 1s 超微細分裂

### 2.1 Fermi接触相互作用（点核近似）

Fermi接触相互作用の式：

```
Δν_F = (16/3) α² (m_e/m_p) (μ_p/μ_N) × (Ry/h)
```

計算結果：

| 項目 | 値 |
|-----|-----|
| Fermi接触項（点核近似） | **1421.16 MHz** |
| 実測値 | 1420.40575177 MHz |
| 点核近似/実測 | 1.000531 |

### 2.2 高次QED補正

主要な補正項：

| 補正項 | 式 | 寄与 |
|-------|-----|------|
| 電子の異常磁気モーメント | a_e = α/(2π) | +0.116% |
| 反跳補正（主要項） | -(m_e/m_p) ln(m_p/m_e) | -0.409% |
| Zemach補正（概算） | -2π (R_p/λ_C) (m_e/m_p) | -0.0007% |

補正係数：1 + a_e + recoil + Zemach = 0.99706

### 2.3 理論値と異常

| 項目 | 値 |
|-----|-----|
| 理論値（補正込み） | **1416.97 MHz** |
| 実測値 | 1420.40575177 MHz |
| **異常** | **約 3.44 MHz** |
| 相対異常 | **0.24%** |

## 4. 異常の比較

| 核種 | 異常（絶対値） | 異常（相対） | 核の特徴 |
|-----|-------------|------------|---------|
| 水素 ¹H | 3.44 MHz | 0.24% | 単一核子、球対称 |
| 重水素 ²H | 109.36 MHz | 33.4% | 2核子系、変形（Q_d ≠ 0） |

重水素の異常が水素の約30倍大きい。これは重水素核の変形（電気四重極モーメント Q_d = 0.286 barn）による不完全なテトラ拘束構造の証拠である。

## 5. 電気四重極相互作用（重水素特有）

### 5.1 重水素の電気四重極モーメント

重水素 ²H の電気四重極モーメント：

```
Q_d = 0.285783 barn = 0.285783 × 10⁻²⁸ m²
```

### 5.2 2p_{3/2} の電気四重極分裂

1s軌道では ∇E = 0（球対称）なので電気四重極相互作用はゼロ。しかし 2p_{3/2} などの状態では有限値を持つ。

```
2p_{3/2} の <r⁻³> = (1/6) (Z/a₀)³ / n³
電気四重極結合定数 b ≈ 971.5 MHz
2p_{3/2} の電気四重極分裂 ≈ b ≈ 971.5 MHz
```

### 5.3 TTT的解釈

²H は陽子+中性子の緩やかな結合系。核は容易に変形する。電気四重極モーメント Q_d ≠ 0 は、2核子系が完全なテトラ拘束を形成できず、**非対称な格子線エネルギー場**を持つことを示している。

## 6. Zemach モーメントと超微細補正

### 6.1 Zemach モーメントの定義

Zemachモーメントは、核の電荷分布と磁気分布の重なりを表す：

```
<r³>_Zemach = ∫∫ d³r d³r' ρ_E(r) ρ_M(r') |r - r'|
```

### 6.2 Zemach 補正

Zemach補正は超微細分裂に以下の寄与を与える：

```
δ_hfs = -2π Z α (m_e/m_p) (r_Z / λ_C) Δν_Fermi
```

| 核種 | Zemach 半径 r_Z | Zemach 補正 |
|-----|----------------|------------|
| 陽子 ¹H | 1.01 fm | -1.79 × 10⁻⁵ |
| 重水素 ²H | 2.60 fm | -2.31 × 10⁻⁵ |

Zemach補正は非常に小さい（0.002%未満）が、核のテトラ拘束構造の非理想性を直接反映している。

### 6.3 核半径のA依存性

| 核種 | A | 計算半径 R=A^(1/3)·r₀ | 実測半径 | 比 |
|-----|---|----------------------|---------|-----|
| ¹H | 1 | 1.20 fm | 0.84 fm | **0.70** |
| ²H | 2 | 1.51 fm | 2.14 fm | **1.42** |
| ³He | 3 | 1.73 fm | 1.97 fm | 1.14 |
| ⁴He | 4 | 1.90 fm | 1.68 fm | 0.88 |

¹H（陽子）は単一核子であり、多核子系の平均場モデル R ∝ A^(1/3) から大きくずれる。これは陽子の「テトラ中」が多核子系の平均場とは**異なる構造**であることを示している。

## 7. TTT的解釈：超微細異常の根源

### 7.1 決定の連鎖

```
① 核内の陽子・中性子のテトラ拘束構造
   → 核の大きさ・対称性・格子線エネルギー場を決定
              ↓
② 核の質量・荷電半径・電気四重極モーメント
   → reduced mass・ポテンシャル・非対称性を決定
              ↓
③ 電子殻のエネルギー準位・超微細構造・同位体シフト
   → 質量シフト（支配的）+ 場シフト（微小）
```

### 7.2 超微細異常の物理的意味

超微細異常 = 核の格子線エネルギー場の非理想性

| 核種 | テトラ拘束の状態 | 異常の大きさ |
|-----|---------------|------------|
| 水素 ¹H | 単一核子、球対称に近い | 小さい（0.24%） |
| 重水素 ²H | 2核子系、変形（Q_d ≠ 0） | 大きい（33.4%） |

- **完全なテトラ拘束** → 核が球対称 → Zemach補正が最小 → 異常が小さい
- **不完全なテトラ拘束** → 核が変形 → Zemach補正が増大 → 異常が大きい
- **電子の電場** → 核の格子線エネルギー場を歪める → 核ポーラリゼビリティ

## 8. 陽子内のテトラ中心と電子軌道

### 8.1 陽子内の3クォーク配置

陽子はuudの3クォーク系。TTTでは「3つの要素の拘束構造」として記述できる。

正三角形配置の重心が「テトラ中心」に相当する：

```
クォーク間距離 a ≈ 1.0 fm
正三角形配置の外接円半径 R = a/√3 ≈ 0.58 fm
```

### 8.2 電子が陽子内部に入る確率

電子が陽子内部（r < R_p）に存在する確率：

```
P_inside ≈ 6.7 × 10⁻¹³
```

確率は極めて小さいが、s軌道電子は核中心に有限の確率振幅を持つ。この確率振幅が核の内部構造（テトラ中心の位置・対称性）を「感じる」ことで、核の有限サイズ効果が生じる。

### 結論

超微細構造の異常は、核内の陽子・中性子のテトラ拘束構造の非理想性（有限サイズ・変形・ポーラリゼビリティ）を反映している。TTTでは、この異常を「格子線エネルギー場の非対称性」として統一的に記述できる。

- 水素（陽子）：単一核子、球対称に近い → 異常が小さい（0.24%）
- 重水素：2核子系、変形（Q_d = 0.286 barn）→ 異常が大きい（33.4%）
