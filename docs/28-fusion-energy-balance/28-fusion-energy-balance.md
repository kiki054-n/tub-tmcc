## 0. 要約

本人の問い：水素核融合で、質量欠損によるエネルギー出力がないことを示したい。入力は水素原子・水素分子・中性子・ヘリウム・電子のエネルギー。質量を空間の比重で比べている誤りを、比重にならない質量としてエネルギーを考えることで示す。

この問いを三つの読みに分け、同じ入力で計算した。

| 読み | 主張 | 結果 |
|---|---|---|
| A | 核融合で外へ出るエネルギーは 0 | **測定と合わない**。中性子・γ線・陽子のエネルギー、太陽の光が測られている |
| B | 質（要素数）は保存され、出るのは量（力・拘束）の差 | **矛盾はない**。ただし今の段階では、出る値は質量の差をそのまま使っているので、予測にはなっていない |
| C | 見かけの質量欠損は、占める空間の数が変わったことによる（比重の誤り） | **合わない**。空間の数が同じ反応どうしで、出力が違う |

羅針盤が指すのは読みB。次にやることは、**ヘリウム核の 28.30 MeV（重水素の 2.22 MeV の 12.72 倍）を、質と量と力から計算で出すこと**。これが出れば、読みB は質量の差を言い換えただけのものではなくなり、予測になる。

## 2. Q 値と測定 [A]

Q＝反応前の質量 − 反応後の質量。二体に分かれる反応では、運動量の保存から軽い方の取り分を出した。

| 反応 | Q（MeV） | 計算した取り分 | 測定 |
|---|---|---|---|
| 水素原子4つ → ヘリウム（太陽の pp 連鎖の正味） | 26.7310 | ― | 太陽の光（§5） |
| 水素分子2つ → ヘリウム | 26.7310 | ― | 原子から出発した場合との差は 8.96 eV |
| D + T → He4 + n | 17.5893 | 中性子 14.048 | 中性子 14.1 MeV |
| D + D → He3 + n | 3.2689 | 中性子 2.449 | 中性子 2.45 MeV |
| D + D → T + p | 4.0327 | 陽子 3.023 | 陽子 3.02 MeV |
| p + n → D + γ | 2.2246 | γ線 2.2232 | γ線 2.2232 MeV |
| n → p + e + ν̄ | 0.7823 | ― | 電子の上限 0.782 MeV |
| e⁻ + e⁺ → γγ | 1.0220 | ― | γ線 0.511 MeV × 2 |
| H + H → H₂（化学、比較用） | 4.478 eV | ― | 解離エネルギー 4.478 eV |

ここで大事なのは、**測っているのは出てきた粒子のエネルギーそのもの**だという点である。中性子の速さ（飛行時間）、γ線の波長、陽子の飛ぶ距離で測る。質量の比較を経由していない。それでも、質量の差 Q と、運動量の保存から出した取り分の両方が、測定と合う。

## 3. 読みA：出力そのものがない

核融合の6反応すべてで、外へ出たエネルギーが測られている。**読みAは測定と合わない。**

## 4. 読みB：質は保存、出るのは量の差

### 4.1 質の収支

[`TTT質量欠損再解釈.md`](../TTT質量欠損再解釈.md) の表（電子 500・陽子 1500・中性子 2000）で数えた。

| 反応 | 質 前 → 後 |
|---|---|
| 水素原子4つ → ヘリウム原子 | 8000 → 8000 |
| D + T → He4 + n（核） | 9000 → 9000 |
| D + D → He3 + n（核） | 7000 → 7000 |
| D + D → T + p（核） | 7000 → 7000 |
| p + n → D + γ | 3500 → 3500 |
| n → p + e + ν̄ | 2000 → 2000 |
| p → n + e⁺ + ν（陽電子を ＋500） | 1500 → 2500 **合わない** |
| p → n + e⁺ + ν（陽電子を −500） | 1500 → 1500 |
| e⁻ + e⁺ → γγ（陽電子を ＋500） | 1000 → 0 **合わない** |
| e⁻ + e⁺ → γγ（陽電子を −500） | 0 → 0 |

**見つかったこと** [B]：陽電子（反電子）の質を **−500**、光子・ニュートリノを 0 とすると、すべての反応で質が保存される。反粒子は質が負、という双極の扱いである（UM＝1 と同じ形）。陽電子を ＋500 とすると、太陽の中で陽子が中性子に変わる段と対消滅で、質が合わなくなる。

### 4.2 質の式

この表の質は、次の式で書ける。[A]

$$\text{質} = 2000 \times (\text{バリオン数}) - 500 \times (\text{電荷})$$

| 粒子 | バリオン数 | 電荷 | 式 | 表 |
|---|---|---|---|---|
| 電子 | 0 | −1 | 500 | 500 |
| 陽電子 | 0 | ＋1 | −500 | −500 |
| 陽子 | 1 | ＋1 | 1500 | 1500 |
| 中性子 | 1 | 0 | 2000 | 2000 |
| 光子・ニュートリノ | 0 | 0 | 0 | 0 |

バリオン数と電荷は、どちらもすべての反応で保存されることが知られている。だから質が保存されるのは必然で、新しい保存則ではない。**率直に言うと、質の保存は今のところ、既知の二つの保存則を一つにまとめた言い方である。** 質の保存を独自の主張にするには、この式から外れる場面（たとえば、陽子が 1500 であること自体が別の理由から出る）を示す必要がある。

### 4.3 出るエネルギー

質が保存されるなら、出るエネルギーはすべて量の差である。その値は測定どおりになる。しかし、それは質量の差 Q をそのまま量の差と呼んだからで、量の差を力から計算したからではない。

**読みBが予測になる条件**：次の数を、質量の測定値を使わずに、力（F_total の各項）と要素数・格子線から出すこと。

| 出すべき数 | 値 |
|---|---|
| ヘリウム核の結合エネルギー | 28.2956 MeV |
| 重水素の結合エネルギー | 2.2246 MeV |
| 比 | 12.720 |

## 5. 太陽での照合

太陽定数 1361 W/m² を、ヘリウム1個あたりに出る熱（26.73 − ニュートリノが持ち去る 約0.59 ＝ 26.14 MeV）で割ると、地球に届くニュートリノの数が出る（ヘリウム1個につき2個）。

| | 個/cm²/s |
|---|---|
| 予測 | 6.50×10¹⁰ |
| 測定（Borexino 2018 [1]、pp ニュートリノのみ） | 約6.1×10¹⁰ |

太陽の光の量から出した数が、地下の検出器で数えたニュートリノの数と、桁も値もほぼ合う（残りは 7Be などのほかの枝）。読みA なら、この数は出てこない。

## 6. 読みC：比重の誤り

### 6.1 置き方

観測している質量は、空間に対する比重である。本当の質量は、観測値に「占める空間の数 × 空間1つの質量」を足したもの。見かけの質量欠損は、反応で空間の数が変わった分だとする。

空間の数：水素分子は2、ヘリウムは1（本人の指定）。ほかは原子・核・自由な粒子を1つにつき1とした（仮置き）。光子・ニュートリノは0。

### 6.2 結果

| 反応 | Δ空間 | Q（MeV） | 空間1つの質量（必要な値） |
|---|---|---|---|
| 水素原子4つ → ヘリウム | ＋3 | 26.7310 | 8.9103 |
| 水素分子2つ → ヘリウム | ＋3 | 26.7310 | 8.9103 |
| D + T → He4 + n | 0 | 17.5893 | 割れない |
| D + D → He3 + n | 0 | 3.2689 | 割れない |
| D + D → T + p | 0 | 4.0327 | 割れない |
| p + n → D + γ | ＋1 | 2.2246 | 2.2246 |
| n → p + e + ν̄ | 0 | 0.7823 | 割れない |

**決め手** [A]：同じ D＋D から出発して、He3＋n と T＋p はどちらも 2空間 → 2空間である。それでも出力は 3.27 MeV と 4.03 MeV で違う。空間の数で決まるなら、二つは同じ値になるはずである。空間の数の数え方を変えても、この二つが同じ形（核1つ＋核子1つ）である限り、この食い違いは消えない。粒子ごとに空間の数を自由に変えて合わせると、それは粒子ごとの質量を言い換えたことになる。

### 6.3 水素分子（2空間）の効き方

| | 値 |
|---|---|
| Q（原子から） − Q（分子から） | 8.956 eV |
| 核融合の出力に対する割合 | 3.35×10⁻⁷ |

水素分子と水素原子の違いは、核融合の出力にはほぼ効かない。差は化学結合の 4.478 eV×2 だけである。

### 6.4 比重について

粒子の質量は、空気や真空に浮かべて量ってはいない。磁場の中で回る周波数（ペニングトラップ）や、出てきた粒子の速さで量っている。浮力（比重）は入っていない。もし「空間に対する比重」が質量の値に入っているとしても、反応の前と後で同じだけ入っていれば、差（Q）では打ち消し合う。差に残るのは、空間の数が変わる分だけで、それは §6.2 で合わなかった。

## 7. 評価

| 項目 | 強さ |
|---|---|
| 核融合で出るエネルギーは測られており、質量の差 Q と合う | [A] |
| 運動量の保存から出した取り分（D-T の中性子 14.05 MeV など）が測定と合う | [A] |
| 太陽の光から出したニュートリノの数が測定と合う | [A] |
| 読みA（出力 0）は測定と合わない | [A] |
| 読みC（空間の数）は、D＋D の二つの枝で食い違う | [A] |
| 質は、陽電子を −500 とすれば全反応で保存される | [A]（計算） |
| 質＝2000×バリオン数 − 500×電荷。質の保存は既知の保存則と同じ中身 | [A] |
| 反粒子の質を負とするのが双極の形（UM＝1）にあたる | [B] |
| 出るエネルギーは量（力・拘束）の差である | [C] 力から 28.30 MeV を出せていない |

**言えること**：質量欠損の分のエネルギーは、確かに外へ出ている。「出力がない」は示せない。言い換えられるのは、出所の名前（質量か、量か）のほうである。
**まだ言えないこと**：その出所が「量」であることを、質量を使わずに計算で示すこと。

## 8. 次に考えること

1. ヘリウム核 28.30 MeV と重水素 2.22 MeV の比 12.72 を、テトラ拘束・格子線の本数・F_total の項から出す。docs/26 の「1本あたり重水素の2.12倍」との関係を確かめる。
2. 陽子 1500・中性子 2000・電子 500 が、2000×バリオン数 − 500×電荷 以外の理由から出るか。出るなら、質の保存は独自の主張になる。
3. 陽電子を −500 とする扱いを、[JA0XUY-BPFF](https://github.com/kiki054-n/JA0XUY-BPFF) の双極（UM＝1）の記録とつなげる。
4. 光子の要素数（12 とした記録がある）と、ここで光子の質を 0 としたことの関係。
