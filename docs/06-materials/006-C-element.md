## TTTの質と量

### 質（要素数）

```
M = 陽子数 × 1500 + 中性子数 × 2000 + 電子数 × 500
  = 6 × 1500 + 6 × 2000 + 6 × 500
  = 9000 + 12000 + 3000
  = 24000
```

### 量（格子線エネルギー）

```
E = 電子数 × 500
  = 6 × 500
  = 3000
```

### 質量比

```
M / M_H = 24000 / 2000 = 12.0
E / E_H = 3000 / 500 = 6.0
```

## 3要素解析

### 質の中心（Cm）

炭素の原子核（陽子+中性子）の質量分布の重心。

### 量の中心（Ce）

4個の価電子の格子線エネルギー分布の重心。

### 中心ずれ（d）

```
・価電子の配置により Ce が Cm からずれる
・d/r の値が結合の種類を決定する
```

---

## 結合特性

### 主な結合の種類

共有結合（sp³, sp², sp混成）

### 特徴

非金属、4価、多様な同素体（ダイヤモンド、黒鉛、フラーレン、グラフェン）

---

## 物質状態

### 常温常圧での状態

固体

### 3相の3要素方程式による説明

```
固体：3つの力（F_M, F_E, F_ME）が強く釣り合う
液体：3つの力が揺らぐ（温度振動）
気体：3つの力が弱い（分子間距離が大きい）
```

## 周期律表での位置

### 第2周期の傾向

```
Li → Be → B → C → N → O → F → Ne
金属性減少 → 非金属性増加 → 希ガス
電離エネルギー増加（全体傾向）
電気陰性度増加
原子半径減少
```

### 隣接元素との比較

左隣: B
右隣: N
