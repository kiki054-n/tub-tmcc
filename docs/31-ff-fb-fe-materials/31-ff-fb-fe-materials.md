## 0. つながる答え

> Ff＝Fb＋Fe のベクトル解析は、材料研究に使える。ただし三つの条件がある。エネルギーは力の**線積分** ∫F·dr で取ること、各項を**測れる量**に結びつけること、原子核・分子・結晶の**階層を分けて**扱うこと。

この日の照合で、ベクトルの見方から次のことが筋よく説明できた。

| 対象 | ベクトルの見方で見えること | 節 |
|---|---|---|
| 水の生成熱 −241 kJ/mol | 反応前後の結合の深さの差。発熱の大半は O–H の極性（Fb の深まり） | §2 |
| 氷が水より軽い（体積 +9.07 %） | 結合の**向き**（四面体）が網目の形を決め、網目が隙間を決める | §4 |
| Si・Ge も固まると膨らむ | 同じ四面体の向きの制約 | §4 |
| CBN と NH₄F | 四面体の向きを保ったまま成分を二つに分ける設計 | §5 |
| FeSi₂ と Si の界面 | 四面体の網目と、四面体 2 個で囲む構造の格子の合い方（ずれ 1.4〜2.0 %） | §6 |

一方、力の大きさの二乗 |F|² をエネルギーの代わりに使うと、結論が逆になる（§2.2）。力からエネルギーへの変換を、項ごと・経路ごとに検討する必要がある（§8）。

## 1. 式と記号

$$\vec F_f = \vec F_b + \vec F_e$$

- **Fb**：求心（引き合う）側の力。原子核と共有電子対の電気的な引力。
- **Fe**：電子雲・環境の斥力。パウリの排他律による電子雲の重なりの拒絶を含む。
- 結合の深さ（拘束の深さ）$D$ は、分離状態から平衡位置 $r_0$ まで引き寄せる過程の線積分で定義する。

$$D = \int_{r_0}^{\infty} \left(-\vec F_b - \vec F_e\right)\cdot d\vec r = V(\infty) - V(r_0)$$

**記号の未決点**：[`docs/30`](../30-fb-fp-forces/30-fb-fp-forces.md) では、Fb を磁石（磁気モーメント）どうしの力、Fp を電荷の力としている。この記録の Fb（電気的な引力）は、docs/30 では異符号の Fp に当たる。また Fe に含まれるパウリの斥力は、古典的な力の場ではなく、電子の運動エネルギーの増加として現れる量子力学の効果である。二つの記録の記号をどう対応させるかは未決（§9）。

## 2. 水の生成熱の内積分解 [A]

### 2.1 数値

| 結合 | 結合エネルギー (kJ/mol) | 本数 (mol) | 小計 (kJ/mol) |
|---|---|---|---|
| H–H | 436 | 1 | 436 |
| O=O | 498 | 0.5 | 249 |
| O–H（平均値） | 463 | 2 | 926 |

ΔH = 685 − 926 = **−241 kJ/mol**。測定値（H₂O 気体）−241.83 kJ/mol と一致する。液体の水なら −285.83 kJ/mol で、生成物が気体であることを明記する必要がある。ΔH と ΔU の差（Δn RT）は −1.24 kJ/mol で小さい。

O–H の 463 kJ/mol は平均値で、1 本目と 2 本目を切るエネルギーは約 497 と約 428 kJ/mol と異なる。

### 2.2 元の文書の §3 で見つかった問題

1. **二種類の θ の混同**：元の文書の §1 の θ は Fb と Fe のなす角で、二原子結合では両者は同じ軸上で逆向きなので常に 180°。§3 の θ は 2 本の O–H 結合のなす角（104.5°）で、別の量である。
2. **合力の式は「折れ線が有利」を示さない**：同じ大きさの斥力 2 本の合力は 2|cos(θ/2)| で、最小（0）になるのは 180°（直線形）である（スクリプト §3）。

| θ | cos θ | 合力の大きさ |
|---|---|---|
| 90° | 0.000 | 1.414 |
| 104.5° | −0.250 | 1.224 |
| 109.47° | −0.333 | 1.155 |
| 180° | −1.000 | 0.000 |

   合力が打ち消し合っても、斥力のエネルギーは減らない。エネルギーは力の線積分で決まり、合力の大きさの二乗とは関係しない。
3. **「直交」と「90° で内積が消える」の矛盾**：104.5° は直交ではない。cos が負であることを斥力の減殺の根拠にするなら、90°（cos = 0）は 104.5° より不利になる。孤立電子対と結合対の配置も、直交ではなく四面体型（約 109.5°）に近い。
4. **角度効果の二重計上**：926 kJ/mol は実際の水（104.5°）を原子に分解するエネルギーで、角度による安定化はすでに含まれている。
5. **仕事の符号**：近づく過程で引力は正の仕事をし、その結果ポテンシャルが下がる。「力の仕事」と「ポテンシャル変化」を区別して書く。

### 2.3 修正案：Pauling の関係による分解

$$D(\text{O–H}) \approx \tfrac12\left[D(\text{H–H}) + D(\text{O–O})\right] + 96.5\,(\Delta\chi)^2$$

Δχ = 3.44 − 2.20 = 1.24 から、極性項は 1 本あたり 148 kJ/mol。O–O 単結合を 146 kJ/mol とすると、

$$\Delta H \approx \underbrace{\tfrac12 D(\text{O=O}) - D(\text{O–O})}_{+103} \;\underbrace{-\,2\times 148}_{\text{極性項}\ -297} \approx -194\ \text{kJ/mol}$$

発熱の大部分は極性項、つまり O–H 結合で Fb が深まることで説明できる。残りの約 −47 kJ/mol は近似誤差の範囲である。

結合角の効果は、別の量として示すのが正しい。水の線形化障壁（約 11,100 cm⁻¹ ≈ 133 kJ/mol、**要確認**）は、折れ線構造が直線形より約 130 kJ/mol 安定であることを示す。その根拠は斥力ベクトルの合成ではなく、曲げたときの軌道エネルギーの変化（Walsh 図）である。

## 3. 階層を分ける：原子核の四面体は化学結合の向きを決めない [A]

### 3.1 酸素16 の核子配置

- 酸素16（陽子 8・中性子 8）は、α 粒子 4 個が正四面体の頂点に並ぶ配置が有力（格子上の第一原理計算：Epelbaum ら 2014、Td 対称の回転バンド：Bijker・Iachello 2014）。
- 殻模型の閉殻（1s に 4、1p に 12）の波動関数は、反対称化した四面体 α 粒子 4 個と数学的に同じになる（Bayman–Bohr）。
- 正八面体 2 個では頂点が 6 × 2 = 12 で、16 にならない。

### 3.2 化学結合との分離

| 比べる量 | 値 | 比 |
|---|---|---|
| O–H 1 本 / 酸素16 の最初の励起準位 | 4.80 eV / 6.049 MeV | 1.26×10⁶ |
| 酸素16 の電荷半径 / O–H 結合長 | 2.699 fm / 0.9572 Å | 2.82×10⁻⁵ |

- 酸素16 の基底状態はスピン 0 で、外から観測できる静的な電気四重極以上の多重極はゼロ。原子核内の四面体の向きは電子に伝わらない。
- 水素と結合しても、核子の配列はほぼ変わらない。変わるのは原子核の位置での電子密度で、メスバウアー分光の異性体シフトや、Be-7 の電子捕獲の速さの化学状態による変化（約 0.1 %）として測れる。
- 原子核が分子に効くのは**電荷と質量**だけ。質量の例として、重水 D₂O は 3.82 °C で凍る（零点振動の違い）。

| 階層 | 四面体をつくるもの | 決めている力 | 大きさ |
|---|---|---|---|
| 原子核 | α 粒子 4 個 | 核力 | 約 3 fm |
| 分子 | 結合対 2 ＋ 孤立電子対 2 | 電子の反発・混成 | 約 1 Å |
| 氷 | 隣り合う水分子 4 個 | 水素結合 | 約 2.8 Å |

三つは同じ四面体の対称性だが、別々の力で決まっている。TTT で扱うなら「なぜ別々の力が同じ幾何学に落ち着くのか」という問いが検証できる形になる。[C]

原子核の内側で核力を Fb と呼ぶ場合、その向きは α 粒子間を結ぶ四面体の 6 辺に沿うと考えるのが自然だが、電磁的な Fb とは別の力として記号を分ける（例：F_b^(N) と F_b^(EM)）。

## 4. 四面体の向きが体積を決める：氷と Si [A]

- 氷 Ih では各水分子が 4 つの隣と水素結合し（O–O 約 2.76 Å）、四面体の網目をつくる。
- 四面体の角度（109.47°）では平らな六角形（120°）をつくれないので、六員環は**いす形**に波打つ。この層が積み重なって c 軸方向に空洞ができ、密度が 0.9167 g/cm³ に下がる（水 0.9998 g/cm³）。凍ると体積は **+9.07 %**。
- 原因は六方晶であることではなく、「4 本・四面体」の制約である。立方晶の氷 Ic（ダイヤモンド型）も六員環ででき、密度はほぼ同じ。
- 液体では水素結合が切れたりつながったりし、環の大きさが 5・6・7 員環とばらつく。正五角形の内角 108° は四面体角 109.47° に近く（差 1.47°）、五員環ができやすい。空洞に分子が入り込み、密度が上がる。密度最大は 4 °C。
- 圧力で網目をつぶした高圧氷（III、V、VI など）は水より重い。
- 同じ四面体の網目をとる Si も、固まると体積 **+10.3 %**（固体 2.33、液体 2.57 g/cm³）。Ge も膨らむ。

ベクトルの見方では、**Fb の向き（結合の方向）が網目の形を決め、網目が密度を決める**。力の大きさではなく向きが体積に効く例である。

## 5. 二成分化：CBN と NH₄F [A]

| 元の構造 | 二成分にしたもの | 分け方 | 共通点 |
|---|---|---|---|
| ダイヤモンド | CBN（c-BN） | B（価電子 3）と N（価電子 5） | 平均 4、四面体網目 |
| 氷 Ih | NH₄F | NH₄⁺（水素結合を 4 本出す）と F⁻（4 本受ける） | どちらも H₂O と同じ 10 電子、ウルツ鉱型 |

- CO₂ は当てはまらない。ドライアイスは直線分子の分子結晶で、液体より重い。数十 GPa の高圧では四面体の網目（CO₂-V）になるが、これは SiO₂ に近い。

### 5.1 同じ仲間の一覧

| 分類 | 例 | 氷との対応 |
|---|---|---|
| 水素結合の四面体網目 | NH₄F、クラスレートハイドレート（メタン、CO₂） | ハイドレートは五員環と六員環のかご |
| 共有結合の網目 | SiO₂（トリディマイト ↔ Ih、クリストバライト ↔ Ic）、BeF₂ | O を Si、水素結合の中点を O に置き換え |
| ダイヤモンド型・閃亜鉛鉱型 | ダイヤモンド、Si、Ge、c-BN、ZnS | 氷 Ic |
| ウルツ鉱型 | w-BN、GaN、AlN、ZnO | 氷 Ih |
| 積み重ね方の多形 | SiC（3C・4H・6H） | 氷の Ih／Ic／積層不整氷 |

### 5.2 結合角で並べた系列

| 結合角 | 六員環の形 | 例 |
|---|---|---|
| 120° | 平面 | グラファイト、h-BN、ベンゼン |
| 109.5° | いす形 | 氷、ダイヤモンド、CBN、SiO₂ |
| 約 95〜100° | 強く波打つ層 | Bi、Sb、黒リン |

h-BN と c-BN は、同じ BN で平面環といす形環の両方をとる。Bi は固まると膨らむ金属である。

## 6. FeSi₂ の構造と界面 [A]（相の温度は要確認）

### 6.1 β-FeSi₂

- 斜方晶、空間群 Cmca、a ≈ 9.86 Å、b ≈ 7.79 Å、c ≈ 7.83 Å、単位胞 48 原子（Fe 16、Si 32）。バンドギャップ約 0.85 eV の半導体。
- 元は蛍石型（CaF₂）。

| 原子 | 周りの原子 | 形 |
|---|---|---|
| Si | Fe 4 個 | 四面体（Si がその中心） |
| Fe | Si 8 個 | 立方体 ＝ 正四面体 2 個を組み合わせた星形八面体 |

- β 相では理想形が歪み（ヤーン・テラー型）、Fe の席が 2 種類に分かれる。この歪みでバンドギャップが開く。
- 相：高温の α 相（正方晶、金属）、β 相、薄膜の準安定 γ 相（理想的な蛍石型）。β 相は約 980 °C の包析反応（α ＋ FeSi → β）と約 940 °C の共析反応（α → β ＋ Si）で生じる（**温度は要確認**）。

### 6.2 Si との界面

| 相手 | 格子の値 (Å) | Si とのずれ |
|---|---|---|
| β の b ÷ √2 a_Si | 7.791 / 7.681 | +1.44 % |
| β の c ÷ √2 a_Si | 7.833 / 7.681 | +1.98 % |
| γ-FeSi₂ | 5.389 | −0.77 % |
| CoSi₂ | 5.365 | −1.22 % |
| NiSi₂ | 5.406 | −0.46 % |

- b と c がほぼ等しいので、向きの違う領域（回転ドメイン）が混ざりやすい。
- CoSi₂ や NiSi₂ と Si の界面では、Si 側の四面体結合が界面を越えてつながり、界面の金属原子は Si の隣人が 8 個から 7 個に減る。

### 6.3 発展形の方向（本人は過去に FeSi₂ を作製した経験がある）

1. **接合を活かす**：高温側で p 型と n 型を電極なしで直接接合した FeSi₂ 熱電発電器（Birkholz ら）。表面の SiO₂ 保護膜で空気中の高温に耐える。
2. **組織の中に界面をつくる**：共析反応で β 相の中に Si を細かく析出させ、フォノンを散乱して熱伝導率を下げる。Cu の添加で β 化が速くなる。
3. **逆の四面体と組み合わせる**：

| 材料 | 構造 | 四面体の中にいる原子 | 熱電特性 |
|---|---|---|---|
| β-FeSi₂ | 蛍石型が歪んだもの | Si が Fe 4 個に囲まれる | p・n 両方可、耐酸化性 |
| Mg₂Si（Mg₂(Si,Sn)） | 逆蛍石型 | Mg が Si 4 個に囲まれる | n 型で性能が高い |
| 高マンガンシリサイド（MnSi≈1.73） | チムニーラダー型 | 長周期構造 | p 型で性能が高い |

FeSi₂ と Mg₂Si は、四面体の内側と外側の原子が入れ替わった表と裏の関係にある。異なるシリサイドどうしの界面接合が課題になる。

## 7. 材料研究に有効である点

Ff＝Fb＋Fe のベクトル解析が材料研究に効くのは、**力の向き**を通して構造を読めるからである。

1. **向き → 網目 → 密度**：Fb の向き（四面体）が網目の形を決め、網目が隙間と体積を決める。氷・Si・Ge・Bi の凝固膨張を一つの見方で説明できる（§4）。[A]
2. **向きを保った成分の置き換え**：四面体の向きの条件を保ったまま成分を分ける・入れ替えると、新しい材料の候補が系統的に出る（CBN、NH₄F、GaN、FeSi₂ ↔ Mg₂Si）（§5、§6）。[A]
3. **界面の合い方**：界面の両側で結合の向きと長さが合うかどうかが、エピタキシーと接合の質を決める（§6.2）。[A]
4. **深さの分解**：結合の深さを、極性による Fb の深まりと、多重結合・角度の寄与に分けられる（§2.3）。[A]

ただし、有効なのは次の条件を守るときである。

- エネルギーは ∫F·dr で取る。|F|² や合力の打ち消しをエネルギーの代わりにしない（§2.2）。
- Fe のうちパウリの斥力は古典的な力ではないので、エネルギーの勘定には量子力学の計算（または測定値）が要る。
- 原子核・分子・結晶の階層を分け、下の階層の形が上の階層の形を決めるとは仮定しない（§3）。

## 8. F のエネルギー変換の検討が必要な理由

力の向きで構造は読めるが、**どれだけのエネルギーが、どの形に変わるか**は向きだけでは決まらない。材料として使う段階（発熱、凝固、熱電変換）では、F からエネルギーへの変換を経路ごとに押さえる必要がある。

### 8.1 変換の経路とその大きさ

| 過程 | F の現れ方 | エネルギー（1 分子・1 結合あたり） | 行き先 |
|---|---|---|---|
| 核の配置換え（酸素16 の励起） | 核力 | 6.049 MeV | γ 線 |
| O–H 結合の形成 | Fb の深まり | 4.80 eV | 光（電磁波）と熱振動（フォノン） |
| 水素結合 | 弱い Fb | 約 0.21 eV | 熱振動 |
| 水の凝固（融解熱 6.01 kJ/mol） | 網目の形成 | 0.062 eV | 潜熱として周囲へ |

### 8.2 凝固での力とエネルギー（スクリプト §7）

- 凍るときの体積増 ΔV = 1.633 cm³/mol。大気を押しのける仕事 P₀ΔV は 0.166 J/mol で、融解熱 6010 J/mol の 2.8×10⁻⁵ 倍にすぎない。
- しかし閉じ込めると、膨らもうとする力は大きな圧力になる。クラペイロンの式で dP/dT = −13.5 MPa/K。エネルギーとしては小さくても、力（圧力）としては大きい。

**力の大きさとエネルギーの大きさは別の量**であり、片方からもう片方を推すことはできない。この点が、F のエネルギー変換を独立に検討する必要がある直接の理由である。

### 8.3 熱電変換（FeSi₂ の場合）

熱から電気への変換効率は、材料の性能指数 ZT と温度で決まる。

$$\eta = \left(1-\frac{T_c}{T_h}\right)\frac{\sqrt{1+ZT}-1}{\sqrt{1+ZT}+T_c/T_h}$$

| T_h / T_c | ZT | 効率 η | カルノー効率 |
|---|---|---|---|
| 900 K / 300 K | 0.2 | 4.5 % | 66.7 % |
| 900 K / 300 K | 0.5 | 9.6 % | 66.7 % |
| 900 K / 300 K | 1.0 | 15.8 % | 66.7 % |

（ZT は計算例で、FeSi₂ の測定値ではない。）

### 8.4 検討すべきこと

1. **Fe の仕事を独立に勘定する**：パウリの斥力によるエネルギーを、電子の運動エネルギーの増加として計算するか、測定値から逆算する。
2. **出たエネルギーの配分**：結合形成で出るエネルギーが、光と熱振動にどう分かれるか（燃焼、発光、[`docs/30`](../30-fb-fp-forces/30-fb-fp-forces.md) §6 の「出たエネルギーの行き先」と接続）。
3. **界面のエネルギー障壁**：FeSi₂ の p-n 接合や電極界面で、∫F·dr を界面を横切って取ると何が出るか（バンドのずれ、ショットキー障壁との対応）。
4. **質量との接続**：[`docs/29`](../29-mass-stores-energy/29-mass-stores-energy.md) の「ためた量 ＝ 力 × 距離」を、化学結合・水素結合・凝固の各段で同じ形に書けるか。
5. **熱電変換の F**：キャリアを動かす力（温度勾配による拡散）と、フォノンを止める界面の力を、Ff＝Fb＋Fe の語彙でどう書くか。[C]
