## 1. 基本変数

| 記号 | 意味 | TTT 対応 |
|------|------|----------|
| **M** | 質（OπO の要素数） | 電子 500、陽子 1500、中性子 2000。不変 |
| **E** | 量（格子線エネルギー） | 結合・運動で変わる |
| **m** | 全質量 | 質の重さ＋量 E/c² |
| **q = Z·F** | 双極の F（電荷） | 陽子 +F、電子 −F、\|F\| = e。FBIF = 1 |
| **r = n·ℓP** | 2点の中心を結ぶ線の長さ | n はプランク空間（OπO）の個数 |

## 2. 方程式（プランク単位）

点 1 から点 2 にかかる力（$\hat r_{12}$ は 1 から 2 へ向かう単位ベクトル）：

$$\vec F_{12}=\frac{F_P}{n^2}\left[\,\alpha\,Z_1Z_2-\frac{m_1m_2}{m_P^{2}}\,\right]\hat r_{12}\;+\;\vec F_R,\qquad F_P=\frac{c^4}{G}$$

- 第1項：双極の F による力。$Z_1Z_2>0$ で反発、$<0$ で引力
- 第2項：全質量による重力。常に引力
- $\vec F_R$：関係項（未定、§6）

---

## 3. 線と釣り合いの原則

1. 空間は OπO で満ち、OπO は線でつながっている。臍の緒はその空間の線である
2. 力 F は、線で結ばれた2点の中心を結ぶ直線の上に働く。すべての点の組が1本ずつ線を持つ
3. 1本の線は両端を同じ大きさ・逆向きに引くか押すので、全体のベクトル和は常に 0 になる
4. 線（関係）は時間を要さずに結ばれている。線を伝わるエネルギーや力の変化は、格子の波として光速で進む
5. すべての力が $1/n^2$ に比例するため、線の釣り合いで決まるのは形（長さの比・角度）だけである。大きさはプランク長と、電子の回転の単位 $\hbar=m_P\ell_P c$ で決まる

---

## 4. 距離の式

ボーア半径はプランク長で次のように書ける。

$$a_0=\ell_P\cdot\frac{m_P}{m_e}\cdot\frac{1}{\alpha}=3.274\times10^{24}\,\ell_P$$

質量の比は、2個の電子を結ぶ1本の線にかかる2つの F の比から出る。

$$\frac{m_P}{m_e}=\sqrt{\frac{1}{\alpha}\cdot\frac{F_E}{F_G}},\qquad \frac{F_E}{F_G}=4.1656\times10^{42}$$

水素分子の陽子間の距離：

$$R=x\cdot\frac{1}{\alpha^{3/2}}\cdot\sqrt{\frac{F_E}{F_G}}\cdot\ell_P$$

x は電子の扱い方で決まる係数（§5）。

## 6. 質と量

- 電子：質 500。$m_ec^2=0.511$ MeV を 500 で割った 1022 eV が、質1単位あたりの量
- 水素原子では、電子の量が 13.6 eV 減る（$\Delta M/M=\alpha^2/2$）
- 臍の緒は空間の線なので、切れて電子に付く O の重さは空間と同じ（基準 0）。測られる質量の差は量の 13.6 eV だけになる
- 中性子 − (陽子 + 電子) = 0.782 MeV。要素数はどちらも 2000 で、差はすべて量
- ヘリウム4の質量欠損 28.30 MeV は、臍の力が中心で 0 になって軽く見える向きと一致する

## 7. 未解決

1. **F の比の導出**：$F_E/F_G=4.17\times10^{42}$ を、OπO 500 個の電子の構造から出す（これが出れば $m_P/m_e$ と距離が TTT の中だけで決まる）
2. **雲の係数 x**：x = 1.414（雲の縮み 1.166）を、電子の 4点テトラ・臍の緒から出す
3. **α**：V5 の予言値 137.0359991882 の式の形と、Core = 108 の必然性
4. **関係項 $\vec F_R$**：作用・反作用と角運動量の保存を満たす形
5. **H₂ の臍の緒**：2個の電子が自分の陽子とつながったままか、両方の陽子とつながるか
