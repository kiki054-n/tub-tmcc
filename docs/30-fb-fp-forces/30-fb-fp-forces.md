## 0. つながる答え

> 物は「粒」と「ためた量」でできている。粒の数は変わらない。物がより深い釣り合いへ移るとき、深くなった分の量が外へ出て、物はその分だけ軽くなる。

$$E_{\text{出る}} = \Delta m\,c^2 = （\text{後の結びつきの深さ}）-（\text{前の結びつきの深さ}）$$

- 深さを決めるのは、押す力と引く力の釣り合い。押す側は動きと同符号の Fp、引く側は異符号の Fp と核力。
- Fb（磁石）は深さではなく向きを決める。対になると外への力が 0 になって閉じる。
- 出た量は、動き → 熱 → 光 となって空間へ広がる。

| 移り方 | 出る量 | 軽くなる割合 |
|---|---|---|
| 水素原子の Fb の反転（21 cm 線） | 5.87 μeV | 6×10⁻¹⁵ |
| 水素＋酸素 → 水（1個あたり） | 2.5 eV | 1.5×10⁻¹⁰ |
| 水素原子2つ → 水素分子 | 4.478 eV | 2.4×10⁻⁹ |
| 陽子＋電子 → 水素原子 | 13.6 eV | 1.4×10⁻⁸ |
| 陽子＋中性子 → 重水素 | 2.22 MeV | 1.2×10⁻³ |
| D＋T → ヘリウム＋中性子 | 17.6 MeV | 3.8×10⁻³ |
| 陽子2＋中性子2 → ヘリウム核 | 28.3 MeV | 7.5×10⁻³ |
| ウラン → かけら2つ（核分裂） | 約 200 MeV | 9×10⁻⁴ |

10 桁を超える範囲で、例外はない。重さの差と出た光のエネルギーは 4×10⁻⁷ で一致する（docs/29 §4）。[A]

TTT が次へ進むのは、この表の「出る量」を、要素数と格子線から計算で出せたときである。[C]

## 1. 式と記号（本人、2026-11-10）

$$F_f = F_b + F_p$$

- 電流 I を **p** と改めた（精神の軸の I＝関係性・共感 と区別するため）。04-relations.md §6 の「F＝Fx＋Fb＋Fi」の未確認点への答え。
- この記録では、Fb を磁石（磁気モーメント）どうしの力、Fp を電荷の力として計算した。Fp を「電流（動き）そのものの力」と読む場合、動いている電荷どうしの力は電荷の力の約 (v/c)² ≈ 5×10⁻⁵ 倍で、平行に動けば引き合う。どちらの読みにするかは未決。
- 物理（ローレンツ力 $\vec F = q\vec E + q\vec v\times\vec B$）では、磁気の力は電流と磁場の積の1項である。足し算で書くなら、Fb と Fp がそれぞれ何の力かを決める必要がある。
- Fb と Fp が直交していれば $|F_f|^2 = |F_b|^2+|F_p|^2$（3²＋4²＝5² の形）。

## 2. 2粒子間の向きと大きさ [A]

### 2.1 向きの決まり方

| | 向き | 距離への効き方 |
|---|---|---|
| Fp | 2粒子を結ぶ線の上。同符号は反発、異符号は引き合う | 1/r² |
| Fb 縦並び・同じ向き（N と S が向き合う） | 引き合う（大きさ 6） | 1/r⁴ |
| Fb 縦並び・逆向き（N と N） | 反発（6） | |
| Fb 横並び・同じ向き | 反発（3） | |
| Fb 横並び・逆向き | 引き合う（3） | |

大きさは (μ₀/4π)μ²/r⁴ を 1 とした倍率。

### 2.2 水素分子（陽子どうし 0.7414 Å）

| | 値 |
|---|---|
| Fp（反発） | 4.20×10⁻⁸ N |
| Fb（縦並び） | 3.95×10⁻¹⁸ N |
| Fb ÷ Fp | 約 10⁻¹⁰ |

陽子どうしの距離は Fb では決まらない。電子2個の磁石は逆向きの対で打ち消し合う。

### 2.3 ヘリウム核（核子どうし 2 fm と置く）

| 組 | Fp | Fb 縦並び | Fb ÷ Fp |
|---|---|---|---|
| 陽子−陽子 | 反発 57.7 N | 7.46 N | 約 0.13 |
| 陽子−中性子 | 0 | 5.11 N（スピンが同じ向きなら縦並びで反発） | ― |

- 核の大きさでは Fb が Fp の約1割まで近づく（1/r⁴ のため）。比は 1/r² で変わる。
- 陽子2・中性子2がそれぞれ逆向きの対になり、核全体の磁石は 0。Fb を中心で足すと 0。
- 核子をつなぐ主役は核力（数百 N の桁、目安）。

## 3. 押す力と引く力の釣り合い

### 3.1 水素原子 [A]

$$E(r)=\frac{\hbar^2}{2m_e r^2}-\frac{ke^2}{r}$$

| | ボーア半径での値 |
|---|---|
| 引く（電荷） | −27.21 eV |
| 押す（動き） | ＋13.61 eV |
| 和 | −13.61 eV |
| 陽子にかかる Fp | 8.24×10⁻⁸ N |

押す分は引く分のちょうど半分（ビリアル定理）。結合エネルギー ＝ ½ F r。

### 3.2 水素原子2つと水素分子 [A]

| | 運動（押す） | 電荷（引く） | 和 |
|---|---|---|---|
| 水素原子2つ | ＋27.21 eV | −54.42 eV | −27.21 eV |
| 水素分子 | ＋31.96 eV | −63.92 eV | −31.96 eV |
| 差 | ＋4.75 | −9.50 | −4.75 |

- 運動エネルギーを多く持つのは水素分子のほう。原子2つが重いのは運動のためではなく、引く側が浅いため。
- 振動の最低エネルギー 0.27 eV を引くと解離エネルギー 4.478 eV。
- 陽子にかかる力は、水素原子 8.24×10⁻⁸ N、水素分子 4.20×10⁻⁸ N（比 1.96）。形は同じ（どちらも和が 0）だが、大きさは同じではない。

### 3.3 止めて見た姿 [A]

| | 陽子にかかる力 |
|---|---|
| 水素原子 | 球の雲が全方向から同じだけ引く → 和 0（打ち消しの 0、中心1つ） |
| 水素分子 | 相手の陽子に押される 4.20×10⁻⁸ N ＋ 雲に引かれる 4.20×10⁻⁸ N → 和 0（釣り合いの 0、中心2つ） |

止めた姿では、核にかかる力は止まった電荷の雲からの電気の力だけで決まる（ヘルマン・ファインマンの定理）。動きは形に入る。

| 動いている姿 | 止めた姿 |
|---|---|
| 電子の運動（31.96 eV） | 雲の大きさと形 |
| 陽子の振動（0.27 eV） | 位置の幅 ±0.087 Å（距離の 12%） |
| 回転（オルト水素） | 向きの幅 |

本人の「水素分子の陽子は空間でつながり力をつないでいる。水素原子は力の相手がいない」は、止めた姿の 0（中心1つ）と 00（中心2つ）の違いとして数値になる。[B]

### 3.4 止めきれないもの [A]

水素分子の陽子は、二つで「離れていく動き」を止めて距離を決めている。振動（0.27 eV、どれだけ冷やしても 0 にならない）と回転（オルト水素はいちばん低い状態でも回る）は残る。

## 4. Fb の大きさ（測定値）[A]

| | 値 | Fp との比 |
|---|---|---|
| 水素原子：陽子と電子のスピンの反転（21 cm 線、1420.405751768 MHz） | 5.87 μeV | 4×10⁻⁷（13.6 eV に対し） |
| 水素分子：陽子どうし（約 58 kHz） | 約 2.4×10⁻¹⁰ eV | 約 10⁻¹⁰ |
| 水素分子：回転が作る磁場と陽子（約 114 kHz） | 約 4.7×10⁻¹⁰ eV | |
| 水素分子：電子どうし | 0（対で打ち消し） | |

- 水素原子では、スピンが逆向き（F＝0）のほうが低い。重なった磁石は向きがそろうほうが低い。
- オルトとパラの差 14.7 meV は磁石の力ではなく、スピンの組み方で許される回転が変わることによる。

## 5. 磁石をくっつけると外への力はなくなるか [A]

| くっつけ方 | 外への力 | 例 |
|---|---|---|
| 逆向きの対 | ほぼ 0 | 水素分子、ヘリウム原子、ヘリウム核、水素原子 F＝0 |
| 同じ向きで一列 | 強まる | 水素原子 F＝1（ふつうの水素の 3/4。1927 年 Phipps–Taylor で磁場により二つに分かれた）、酸素分子（不対電子2個、液体酸素は磁石につく） |

Fp も同じ形：＋と−がくっついて中性になると、外への力はほぼ 0（近くでファンデルワールス力が残る）。

### 5.1 誰が向きを決めるか

| 本人の記述 | 照合 |
|---|---|
| 水素分子は陽子どうし（Fb で）つながらない | 合う。陽子どうしの磁気の結びつきは 10⁻¹⁰ eV。つないでいるのは電子の雲を通した Fp |
| 水素分子は電子が NS の向きを決めている | 合わない。電子は対で磁場を出さない。オルトとパラは入れ替わりにくく（固体でも1時間に約2%）、入れ替えには不対電子を持つ触媒が要る。陽子の向きは回転との組み合わせで決まる |
| ヘリウムは中性子が介在し陽子の向きを合わせる | 中性子なしでは陽子どうしは結びつかない（陽子＋陽子は不安定）。陽子＋中性子はスピンが同じ向きのときだけ結びつく（重水素）。陽子どうしが逆向きの対になるのはパウリの原理。向きを選ぶのは Fb（数 N）ではなく、スピンで強さの変わる核力 |

## 6. 出たエネルギーの行き先 [A]

| 反応 | 何に変わるか | どこへ |
|---|---|---|
| D＋T → He4＋n | 中性子 14.05 MeV、ヘリウム 3.54 MeV の動き | 炉の壁の外側の層で減速 → 熱 → 発電 |
| 太陽（26.73 MeV） | γ線・消滅光・原子核の動き、ニュートリノ 約2% | γ線は太陽の中で熱になり、表面から可視光で宇宙へ。ニュートリノは素通りして地球へ |
| D＋D → He4＋γ（まれ） | γ線 23.85 MeV | 光として外へ |
| H＋H → H₂ | 4.478 eV | 3つめの原子の動き（気体が温まる）か、表面の熱 |
| 水素原子の Fb 反転 | 21 cm の電波 | 宇宙へ |

$$\text{F でつなぐ}\to\text{動き}\to\text{熱（揺れ）}\to\text{光}\to\text{空間へ}$$

出た分だけ残った物は軽くなり、その質量を出ていった動きと光が運ぶ。全体で見ればエネルギーは保存される。

### 6.1 質量保存の法則について

- 出た光や動きまで箱に入れておけば、箱全体の質量は変わらない。
- できた物だけを量ると、出ていった分だけ軽い。化学で質量保存が成り立って見えるのは、差が 10⁻⁹〜10⁻¹⁰ で天秤に出ないから。
- 「質量が分解するとエネルギーになる」は、水素では逆。分けるには入れ、つなぐと出る。分けて出るのは鉄より重い核だけ。

### 6.2 水素の燃焼（2H₂＋O₂ → 2H₂O、気体）

| 段階 | エネルギー |
|---|---|
| 水素分子2つを分ける | 8.96 eV を入れる |
| 酸素分子を分ける | 5.12 eV を入れる |
| 水2個につながる | 19.02 eV が出る |
| 差し引き | 4.95 eV が出る（水1個 約2.5 eV、241.8 kJ/mol と合う） |

実際の燃焼は H・O・OH のかけらの連鎖で進み、点火で入れた分を出た分がまかなう。

## 7. 核融合と核分裂：箱のたとえ [A]

| | 核分裂（U235） | 核融合（D＋T） |
|---|---|---|
| 箱 | 1つが2つになる | 2つが1つになる（箱は残る） |
| 1回で出る | 約 200 MeV | 17.6 MeV |
| 核子1個あたり | 約 0.85 MeV | 約 3.5 MeV |
| 出どころ | 閉じ込めていた陽子の押し合い（Fp）の解放 | より深い引き合い（核力） |
| 粒の数 | 変わらない | 変わらない |

### 7.1 核分裂の内訳（ワイツゼッカーの式、U236 を半分に）

| | 前 | 後 | 差 |
|---|---|---|---|
| 箱の表面のエネルギー | 680 MeV | 856 MeV | ＋177（入れる） |
| 陽子どうしの押し合い Fp | 974 MeV | 613 MeV | −360（出る） |
| 差し引き | | | 約 184 MeV が出る |

- 箱を作るにはエネルギーが要る。出るのは押し合いの解放で、箱の創出はその一部を払う側。
- かけら（Kr92＋Ba141）が接した瞬間の押し合いは約 250 MeV。実際は変形して離れているので小さく、測定されるかけらの運動エネルギーは約 170 MeV。
- 核の密度はどの核でも同じ（0.138 個/fm³）。かけらは質量も体積も半分で、比重は変わらない。docs/08 の「体積比で質量が半分に見える」はこの測定と合わない。

鉄より軽い核は箱をまとめると深くなり、重い核は割ると深くなる。向きは逆でも規則は一つ（§0）。
