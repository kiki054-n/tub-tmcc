## 1. リポジトリ概要

TUB-TMCCは、Tri-Tetra Theory（TTT / OOπ）の幾何学的語彙を用いて、
結合と物質状態を統一的に記述する理論の草案リポジトリです。

**核心命題**: すべての力は「格子線エネルギー場」のスケール存性として連続的に変化する。
原子核内の強い力・電磁力・磁気力から分子間力まで、同じ根源的な幾何学的構造から生じる。

**3要素の統一**:
- **質（M）**: 要素数（不変）
- **量（ΔM）**: 格子線エネルギーの蓄積（可変）
- **関係（R）**: 力の中和・拘束・再配分

### 4.1 調整不能な予言の成功

| 物理量 | TTT値 | 実験値 | 一致度 |
|--------|-------|--------|--------|

→ すべて同固定語彙（V4=4, VTB=5, V8=6, VPB=7, V12=20, V20=12, Core=108）から導かれる。

### 4.2 幾何学的統一の証拠

- **電磁力と強い力の統一**: α⁻¹ と α_s が同じ「五角双錘 + 正四面体」の構造から派生
- **色対称性の必然性**: 双対変換（5→3）がクォークの3色を幾何学的に生成
- **ねじれ角の調整不能性**: 3つの独立な幾何学的経路がすべて 36° に収束
- **SU(3) β関数係数の幾何学的起源**: VPB + V4 = 11 = SU(3) の1ルプβ関数係数

### 4.3 分子設計への応用可能性

- **TTT的分子設計の5ステップ**: 目標物性の幾何学的解釈 → 幾何学的構造の設計 → 格子線エネルギー配置の計算 → 安定性の評価 → 実験的合成と検証

## 6. 理論の哲学

### 6.1 質量欠損の再解釈

TTTでは「質量欠損」を否定し、以下のように捉える:
- **質 M**: 要素数（不）
- **量 ΔM**: 格子線エネルギーの蓄積（可変）
- **力**: 中和・拘束・再配分の過程

水素原子の崩壊や水爆のエネルギー放出は「質量の消失」ではなく、
「力が1つにつながる中和過程のエネルギー放出」である。

### 6.2 空間は粒子である

粒子条件は「囲うもの」と「要素」である。
空間は「誕生していない」状態ではなく、4×4×4=64の空間に54個のOOπO粒子が存在し、
余裕がある状態である。

### 6.3 双極的視点

TTTの核心哲学は「平面で見るか球面で見るか」の双極的視点の違いである。
これはコペルニクスの天動説/地動説の転換と同じ構造である。
