3. 読みC：Q = (反応前の空間の数 − 反応後の空間の数) × 空間1つの質量 で説明できるか
  空間の数え方（本人の指定）：水素分子は2空間、ヘリウムは1空間。
  それ以外は、原子・核・自由な粒子を1つにつき1空間とする（仮置き）。光子・ニュートリノは0。
  水素原子4つ → ヘリウム原子（太陽の pp 連鎖の正味）      Δ空間 +3  Q   26.7310 MeV  必要な空間1つの質量   8.9103
  水素分子2つ → ヘリウム原子                    Δ空間 +3  Q   26.7310 MeV  必要な空間1つの質量   8.9103
  D + T → He4 + n                    Δ空間 +0  Q   17.5893 MeV  必要な空間1つの質量   （割れない）
  D + D → He3 + n                    Δ空間 +0  Q    3.2689 MeV  必要な空間1つの質量   （割れない）
  D + D → T + p                      Δ空間 +0  Q    4.0327 MeV  必要な空間1つの質量   （割れない）
  p + n → D + γ                      Δ空間 +1  Q    2.2246 MeV  必要な空間1つの質量   2.2246
  n → p + e + ν̄（中性子の崩壊）             Δ空間 +0  Q    0.7823 MeV  必要な空間1つの質量   （割れない）
  同じ D + D から出発して、He3 + n と T + p はどちらも 2空間 → 2空間。
  それでも Q は 3.2689 と 4.0327 MeV で違う。
  空間の数だけで決まるなら、この二つは同じ値になるはず。→ 空間の数だけでは説明できない。
