3. 斥力ベクトル2本の合力（同じ大きさ 1、なす角 θ）
   |F_total|² = 1 + 1 + 2cosθ  →  |F_total| = 2|cos(θ/2)|
   θ =   90.00°  cosθ = +0.000  |F_total| = 1.414
   θ =  104.50°  cosθ = -0.250  |F_total| = 1.224
   θ =  109.47°  cosθ = -0.333  |F_total| = 1.155
   θ =  120.00°  cosθ = -0.500  |F_total| = 1.000
   θ =  150.00°  cosθ = -0.866  |F_total| = 0.518
   θ =  180.00°  cosθ = -1.000  |F_total| = 0.000
   → 合力が最小（0）になるのは 180°（直線形）。折れ線 104.5° は最小ではない。
   → 合力の大きさの二乗はエネルギーではない。エネルギーは ∫F·dr。
  水の線形化障壁 約 11100 cm⁻¹ = 133 kJ/mol（要確認）
