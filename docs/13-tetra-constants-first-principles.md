# 定数の第一原理的導出：テトラ拘束・炭素12・正8面体配置

> G_M, G_E, G_ME, G_R, α_E, β, f(θ,φ) の関係を、正4面体の双多面体（正8面体）の幾何と炭素12の核構造から第一原理的に導出する
> 草案 v0.1 / 2026-11-07

---

## 核心主張

4つの万有引力定数 G_M, G_E, G_ME, G_R と電気的結合定数 α_E、質-量結合定数 β、角度依存関数 f(θ,φ) は、正4面体の双多面体である正8面体の幾何と、炭素12の核構造（6点の正8面体配置）から第一原理的に導出できる。正4面体の6辺が正8面体の6頂点に対応し、各辺の3要素（質M・量E・関係R）の配置が定数間の関係を決定する。

## 1. 正4面体と正8面体の双多面体関係

### 1.1 双多面体の定義

正4面体と正8面体は双多面体（dual polyhedron）の関係にある：

- 正4面体の**4頂点** ↔ 正8面体の**4面**
- 正4面体の**6辺** ↔ 正8面体の**6頂点**
- 正4面体の**4面** ↔ 正8面体の**4頂点**

### 1.2 正4面体の幾何

エッジ長を a とする正4面体：

| 量 | 式 | 値（エッジ長=1）|
|---|-----|---------------|
| 外接球半径 | R = a·√6/4 | 0.6124 |
| 体積 | V = a³/(6√2) | 0.1179 |
| 表面積 | A = √3·a² | 1.7321 |
| 体積/表面積比 | V/A = a/(6√6) | 0.0680 |

### 1.3 正8面体の幾何

エッジ長を b とする正8面体：

| 量 | 式 | 値（エッジ長=1）|
|---|-----|---------------|
| 外接球半径 | R = b/√2 | 0.7071 |
| 対頂点間距離 | 2R = b·√2 | 1.4142 |
| 隣接頂点間距離 | b | 1.0000 |

### 1.4 双多面体のスケール関係

正4面体の辺の中点が正8面体の頂点となる：

```
正4面体の辺の中点間距離 = 正8面体のエッジ長
正4面体のエッジ長 a = √2 × 正8面体のエッジ長 b
```

## 2. 炭素12の核構造：正8面体6頂点配置

### 2.1 核子配置モデル

炭素12（6陽子 + 6中性子 = 12核子）の核構造を、正8面体の6頂点に核子ペアを配置するモデルで記述する：

```
頂点1 (+X): (R, 0, 0)     → 陽子 + 中性子
頂点2 (-X): (-R, 0, 0)    → 陽子 + 中性子
頂点3 (+Y): (0, R, 0)     → 陽子 + 中性子
頂点4 (-Y): (0, -R, 0)    → 陽子 + 中性子
頂点5 (+Z): (0, 0, R)      → 陽子 + 中性子
頂点6 (-Z): (0, 0, -R)     → 陽子 + 中性子
```

### 2.2 核のスケール

| パラメータ | 値 |
|-----------|-----|
| 炭素12の核半径（実測概算） | R ≈ 2.47 fm |
| 正8面体の外接球半径 | R ≈ 1.27 fm（エッジ長 1.8 fm） |
| 隣接核子間距離 | a ≈ 1.80 fm |
| 対頂点間距離 | 2R ≈ 2.55 fm |

### 2.3 正8面体の12ッジ

正8面体は12本のエッジを持ち、各エッジは2つの核子ペア間の相互作用を表す：

```
エッジ1-4:  頂点0(+X) と 頂点2(+Y), 3(-Y), 4(+Z), 5(-Z) の4本
エッジ5-8:  頂点1(-X) と 頂点2(+Y), 3(-Y), 4(+Z), 5(-Z) の4本
エッジ9-12: 赤道面 頂点2(+Y), 3(-Y), 4(+Z), 5(-Z) 間の4本
```

## 3. 3要素テトラ拘束モデル

### 3.1 3要素の定義

TTTの3要素：

| 要素 | 記号 | 物理的意味 |
|-----|------|----------|
| 質 | M | 素数（不変） |
| 量 | E | 格子線エネルギー（可変） |
| 関係 | R | 力の配分・方向性 |

### 3.2 正4面体の6辺と3要素の配置

正4面体の6辺に3要素を配置：

```
辺の種類        本数    相互作用
─────────────────────────────────
M-E 辺          2本    質-量の相互作用
M-R 辺          2本    質-関係の相互作用
E-R 辺          2本    量-関係の相互作用
```

### 3.3 対称テトラと非対称テトラ

| 種類 | 特徴 | 拘束エネルギー |
|-----|------|--------------|
| 対称テトラ | 全辺等長 → 3つの相互作用が等価 | E_tetra = k_tetra × (6a) |
| 非対称テトラ | 辺長が異なる → 相互作用の強度が異なる | E_tetra = Σ kᵢⱼ · aᵢⱼ |

炭素12の核構造は非対称テトラとして記述される。正8面体の6頂点配置により、各エッジの長さ（核子間距離）が異なり、3要素の相互作用の強度が変化する。

## 4. 万有引力定数の第一原理的導出

### 4.1 基本単位の定義

TTTの基本単位：

| 単位 | 記号 | 導出 | 値 |
|-----|------|------|-----|
| 単位質量 | m₀ | m_p / N_p | 1.115 × 10⁻³⁰ kg |
| 単位量エネルギー | e₀ | m_e·c² / N_e | 1.637 × 10⁻¹⁶ J |
| 単位長さ | a₀ | ボーア半径 | 5.292 × 10⁻¹¹ m |

### 4.2 G_M の導出：質-質相互作用

```
G_M = g_M · a₀³ · c² / m₀²
```

| パラメータ | 値 |
|-----------|-----|
| 無次元結合定数 g_M | 6.23 × 10⁻⁵⁷ |
| G_M（理論値） | ≈ G_Newton = 6.674 × 10⁻¹¹ m³/(kg·s²) |

### 4.3 G_E の導出：量-量相互作用

```
G_E = g_E · a₀ · c² / e₀²
```

| パラメータ | 値 |
|-----------|-----|
| 無次元結合定数 g_E | 1.94 × 10⁻⁴⁰ |
| G_E（理論値） | クーロン定数と関連 |

### 4.4 G_ME の導出：質-量相互作用

```
G_ME = g_ME · √(G_M · G_E)
質-量変換係数 = (m_p/m_e) · (N_e/N_p) = 612.05
```

| パラメータ | 値 |
|-----------|-----|
| 無次元結合定数 g_ME | 6.73 × 10⁻⁴⁶ |
| G_ME | 重力と電磁気の混合相互作用 |

### 4.5 G_R の導出：斥力-方向性相互作用

```
G_R = g_R · a₀⁴ · c² / e₀
```

| パラメータ | 値 |
|-----------|-----|
| 無次元結合定数 g_R | 1.76 × 10⁻¹⁴ |
| G_R（水素結合から逆算） | 7.58 × 10⁻²³ m⁴·N/J² |

## 5. 微細構造定数との関係

### 5.1 電気的結合定数 α_E

```
α_E = G_E · e₀² / (ħ c · a₀²) = 2.30 × 10⁻⁸
```

α_E は電気的相互作用の無次元強度を表す。

### 5.2 質-量結合定数 β

```
β = G_ME · m₀ · e₀ / (ħ c · a₀) = 7.34 × 10⁻⁵⁶
```

β は質と量の混合相互作用の無次元強度を表す。

### 5.3 微細構造定数 α との関係

```
α = 7.297 × 10⁻³
1/α = 137.036
```

α は電磁相互作用の無次元強度。TTTでは α は正4面体の体積/表面積比と関連する可能性がある：

```
正4面体の体積/表面積比 = a/(6√6) ≈ 0.0680
```

## 6. f(θ,φ) の幾何的導出

### 6.1 正8面体の頂点方向

正8面体の6頂点の方向（θ, φ）：

| 頂点 | θ | φ |
|-----|---|---|
| +X | 90° | 0° |
| -X | 90° | 180° |
| +Y | 90° | 90° |
| -Y | 90° | 270° |
| +Z | 0° | 0° |
| -Z | 180° | 0° |

### 6.2 球面調和関数展開

正8面体対称性（O_h）を持つ f(θ,φ) は球面調和関数で展開できる：

```
f(θ,φ) = Σ cₗₘ Yₗₘ(θ,φ)
```

正8面体対称性により、l = 0, 4, 6, ... の成分のみが非ゼロ：

```
f(θ,φ) = c₀₀ Y₀₀ + c₄₀ Y₄₀ + c₄₄ Y₄₄ + c₄₋₄ Y₄₋₄ + c₆₀ Y₆₀ + ...
```

### 6.3 簡易モデル

```
f(θ,φ) = 1 + a₄ · Y₄₀(θ,φ)
```

Y₄₀(θ,φ) = √(9/4π) · (35cos⁴θ - 30cos²θ + 3)/8

## 7. 定数間の関係式のまとめ

### 7.1 4つの万有引力定数

| 定数 | 式 | 無次元結合定数 | 物理的意味 |
|-----|-----|--------------|----------|
| G_M | g_M · a₀³ · c² / m₀² | g_M = 6.23×10⁻⁵⁷ | 質-質相互作用 |
| G_E | g_E · a₀ · c² / e₀² | g_E = 1.94×10⁻⁴⁰ | 量-量相互作用 |
| G_ME | g_ME · √(G_M · G_E) | g_ME = 6.73×10⁻⁴⁶ | 質-量混合相互作用 |
| G_R | g_R · a₀⁴ · c² / e₀ | g_R = 1.76×10⁻¹⁴ | 斥力-方向性相互作用 |

### 7.2 2つの結合定数

| 定数 | 式 | 値 | 物理的意味 |
|-----|-----|-----|----------|
| α_E | G_E · e₀² / (ħ c · a₀²) | 2.30×10⁻⁸ | 電気的結合強度 |
| β | G_ME · m₀ · e₀ / (ħ c · a₀) | 7.34×10⁻⁵⁶ | 質-量混合結合強度 |

### 7.3 角度依存関数

```
f(θ,φ) = Σₗₘ cₗₘ Yₗₘ(θ,φ)  （l = 0, 4, 6, ...）
```

## 8. 炭素12の正8面体配からの洞察

### 8.1 決定の連鎖

```
① 正4面体の双多面体 = 正8面体
   → 6辺 ↔ 6頂点 の対応
              ↓
② 炭素12の核構造 = 正8面体の6頂点に核子ペア配置
   → 12本のエッジ = 12の核子間相互作用
              ↓
③ 各エッジに3要素（M, E, R）を配置
   → 3種類の相互作用（M-E, M-R, E-R）
              ↓
④ 4つの万有引力定数 G_M, G_E, G_ME, G_R
   → 正4面体の幾何（a₀, m₀, e₀）と無次元結合定数（g_M, g_E, g_ME, g_R）
              ↓
⑤ 微細構造定数 α_E, β, f(θ,φ)
   → 正8面体の対称性（O_h）から球面調和関数展開
```

### 8.2 TTT的解釈

炭素12の核構造は、正8面体の6頂点に6対の陽子-中性子ペアを配置したモデルで記述できる。この配置から：

- 正4面体の6辺が正8面体の6頂点に対応
- 各辺の3要素（M, E, R）の配置が定数間の関係を決定
- 正8面体の対称性（O_h）が f(θ,φ) の球面調和関数成分を制限
- 不完全なテトラ拘束（辺長の非対称性）が超微細異常の根源
