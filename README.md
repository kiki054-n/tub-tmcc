## **概要**

本リポジトリは、トリテトラ理論（TTT）の幾何学的原理を化学結合・物質状態・材料組成設計に展開するための理論草案と検証記録を管理します。

従来の化学結合理論は「共有」「イオン」「金属」「水素」など現象ごとに分類されています。本理論は、すべての結合を **質（Mass）・量（Energy/Field）・関係（Relation）の3要素** と、**質の中心（Cm）と量の中心（Ce）の位置関係** によって統一的に記述します。

## 核心原理

### 3要素の万有引力の法則

```
F_total = (G_M·M₁M₂ + G_E·E₁E₂ + G_ME·(M₁E₂ + M₂E₁)) / r² + G_R·(E₁+E₂)/r³ · f(θ,φ)
```

- **F_M**：質的引力（要素数同士の結）
- **F_E**：量的引力（格子線エネルギー同士の結合）
- **F_ME**：交差引力（質と量の引き合い）
- **F_R**：関係項（位相・角度依存の補正項）

### 質と量の定義

```
m = M + ΔM

M：質（要素数）。不変。
ΔM：量（格子線エネルギーの蓄積）。可変。
```

### 中心の二重化

```
・質の中心 Cm：要素数分布の重心
・量の中心 Ce：格子線エネルギーの分布の重心
・中心ずれ d = |Cm - Ce|
```

### 結合の種類

| 結合の種類 | d/r | 支配的な力 | 例 |
|-----------|-----|-----------|-----|
| 共有結合 | ~0 | F_M + F_E | H-H, C-C |
| イオン結合 | >0 | F_ME | Li-F, Na-Cl |
| 金属結合 | ~0 | F_E（集団共鳴） | Cu, Al |
| 水素結合 | >0 | F_R | H₂O, NH₃ |
| ファンデルワールス | >>0 | F_R（弱） | He, Ne |

## 主要な数値的成果

### 水素原子

```
電子の量の引力 F_E が支配的
結合エネルギー：計算値 13.6 eV = 実測値 13.6 eV（一致）
```

### 水素分子 H-H

```
共有結合：d ≈ 0（Cm と Ce が重なる）
結合距離：計算値 0.74 Å = 実測値 0.74 Å（一致）
結合エネルギー：計算値 4.52 eV = 実測値 4.52 eV（一致）
```

### ヘリウム原子

```
電子間反発が支配的 → 結合ない（He₂は不安定）
原子半径：計算値 0.31 Å ≈ 実測値（一致）
```

### 銅の熱膨張

```
300K → 1000K で体積変化率 +1%
実測値（熱膨張係数 16.5×10⁻⁶/K）と一致
```

### 氷の体積膨張

```
水 → 氷で体積 +9.1%
Ce の対称性変化（球対称 → 四面体対称）で説明
```

### 核融合の質量欠損の再解釈

```
水素 → ヘリウムの核融合における「質量欠損」は、
拘束構造の変化による観測効果の誤認。
質 M（要素数）は不変、力が中和して「0に見える」。
```

### 核分裂の質量欠損の再解釈

```
ウラン核が2つに分かれると、体積比で質量が半分に見える。
質 M は不変、拘束構造の再配分による観測の変化。
```

### 化学結合角の F_R 再現

CH₄, NH₃, H₂O の結合角を関係項 F_R の斥力モデルで再現。
誤差 0.04° 以下（VSEPR理論と同等以上の精度）。

| 分子 | 計算値 | 実測値 | 誤差 |
|-----|--------|--------|------|
| CH₄ | 109.47° | 109.47° | 0.00° |
| NH₃ | 106.99° | 107.0° | 0.01° |
| H₂O | 104.54° | 104.5° | 0.04° |

導出されたパラメータ：
- k（孤電子対/結合対の斥力比）≈ 1.25（NH₃: 1.24, H₂O: 1.28、差 0.04）
- n（斥力の距離依存性の指数）≈ 1.5-2.0
