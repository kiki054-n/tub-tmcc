# 核反応・化学反応の統一的記述：質量欠損の誤認と力の中和

> 核分裂・核融合・化学反応を、質・量・関係の3要素と拘束構造の再配分として統一的に記述する
> 草案 v0.1 / 2026-11-07

---

## 核心主張

現代物理は「質量欠損 Δm がエネルギー E = Δm·c² に変換される」と説明しているが、これは誤認である。

- **質 M（要素数）は不変**：核反応・化学反応の前後で変わらない
- **変わるのは拘束構造と力の中和状態**：距離 r の消失・再配分によって、外部からの観測が変化する
- **エネルギー放出は、より安定な拘束状態への移行の結果**：質量が変換されたのではない

---

## 1. 核融合：水素 → ヘリウム

### 現代物理の誤認

```
水素原子 → ヘリウム核 + エネルギー
「質量が 0.7% 欠損してエネルギーに変換された」
```

### TUB-TMCCの解釈

水素分子では陽子同士が距離 r を持ったまま別々の中心を持つ。

```
水素分子 H₂:
  陽子A ○──────○ 陽子B
        ↑ 距離 r あり ↑
        2つの質的中心 Cm が別々
```

中性子と結びついてヘリウム核が形成されと、陽子同士の距離 r が消失し、力が一つにつながって中和する。

```
ヘリウム核 ⁴He:
  (陽子A・中性子・中性子・陽子B)
        1つの拘束構造
        力が中和して「0に見える」
```

| | 水素分子 H₂ | ヘリウム核 ⁴He |
|---|---|---|
| 質 M（要素数） | 2陽子＋2電子 | 2陽子＋2中性子＋2電子 |
| 陽子間距離 r | あり（共有結合） | 消失（テトラ拘束） |
| 質的中心 Cm | 2つ | 1つに統合 |
| 力の状態 | 距離あり、外向きに働く | 中和、外向きの力が消失 |
| 観測される質量 | 2つの質量の和 | 1つの質量（「欠損」に見える） |
| エネルギー | — | 中和された力のエネルギーが放出 |

**結論**：質は変わらない。力が一つにつながって中和し、外部から見ると「質量が減少した」ように観測されるだけ。

## 2. 核分裂：ウラン → 2つの核

### 現代物理の誤認

```
ウラン核  2つの中度の核 + 中性子 + エネルギー
「質量が欠損してエネルギーに変換された」
```

### TUB-TMCCの解釈

ウランは1つの大きな核。核が2つに分かれると、体積比で「質量が半分」に見える。

| | ウラン核（1つ） | 分裂後（2つの核） |
|---|---|---|
| 質 M（要素数） | 92陽子＋中性子 | 合計で同じ（不変） |
| 拘束構造 | 1つの大きな構造 | 2つの小さな構造 |
| 単位体積あたりの観測質量 | 大きい | 半分に見える |
| 拘束の状態 | 過剰拘束（不安定） | 再配分され安定化 |
| エネルギー | — | 過剰拘束エネルギーが放出 |

重い核（ウラン）は「拘束が過剰」な状態。核が大きすぎて、テトラ拘束が最適化できない。分裂することで、2つの核がそれぞれより安定な拘束状態に移行し、その差分がエネルギーとして放出される。

**結論**：質は変わらない。拘束構造が再配分され、観測方法が変化しただけ。

## 3. Fe/Niへの収束：拘束の最適化

結合エネルギ/核子の曲線は、Fe-56やNi-62あたりでピークを持つ。これは拘束の最適点である。

```
エネルギー（拘束エネルギー/核子）
  ↑
重い核 ─┐
       │    ╱╲ Fe/Ni（ピーク）
       │   ╱  ╲
       │  ╱    ╲
       │ ╱      ╲
軽い核 ─┘        ╲ 重い核
  └────→ 核融合    核分裂 ←────┘
```

| 核の種類 | 拘束の状態 | エネルギー放出の方向 |
|---------|----------|-------------------|
| 軽い核（H, He, Li...） | 拘束が不完全、力が外向き | 核融合方向へ（拘束が強まる） |
| Fe, Ni | 拘束が最適、力が完全に中和 | 安定な状態（エネルギー最小） |
| 重い核（U, Pu...） | 拘束が過剰、構造が不安定 | 核分裂方向へ（拘束が再配分される） |

エネルギーが放出されるのは、常に「より安定な拘束状態へ向かう方向」である。Fe/Niは拘束の最適点であり、そこに向かって軽い核は融合し、重い核は分裂する。

## 4. 化学反応エネルギー：核反応と同じ構

化学反応も、本質的には核反応と同じ「拘束構造の再配分」である。

### 化学反応における3要素の力

```
F_total = F_M + F_E + F_ME + F_R
```

| 力 | 化学反応での役割 |
|---|--------------|
| F_M（質的引力） | 原子核同士の結合（共有結合の芯） |
| F_E（量的引力） | 電子雲の格子線エネルギー同士の結合 |
| F_ME（交差引力） | 原子核と電子雲の引き合い（イオン性） |
| F_R（関係項） | 角度・位相依存の結合（方向性、水素結合） |

### 化学反応の例：H₂ + O → H₂O

```
反応前:
  H─H    O
  共有結合  単独原子

反応後:
  H─O─H
  新しい拘束構造（角度 104.5°）
```

- **質 M**：H, O の要素数は不変
- **変わるのは**：電子雲の拘束構造（格子線の再配分）
- **エネルギー放出**：新しい拘束構造がより安定なため、過剰エネルギーが放出
- **観測**：「質量は保存される」（化学反応では質量欠損が観測されない）

化学反応では核反応に比べて拘束エネルギーの変化が小さいため、質量変化は検出限界以下である。しかし構造は同じ：**質は不変、拘束構造が変化し、エネルギーが放出される**。

## 5. 原子核の持つ力と電荷、線磁力

### 原子核に働く力の分解

原子核内では、以下の力が複雑に絡み合っている：

```
核内の力:
├── 質的引力 F_M：核子（p, n）同士の要素数による結合
├── 量的引力 F_E：核子の双極的格子線ネルギーによる結合
├── 交差引力 F_ME：質（核子）と量（格子線エネルギー）の引き合い
└── 関係項 F_R：角度・位相依存の補正（テトラ拘束の対称性）
```

### 電荷と線磁力

- **電荷**：プロトンの正電荷は、格子線エネルギーの「外向きの力」の表れ
- **線磁力**：格子線が回転・振動することで生じる磁場的効果
  - 電子のスピン：格子線の回転方向
  - 核磁気：核子の格子線回転の集合効果

### 核内の運動と格子振動

核子は核内で高速に運動しているが、これは格子線エネルギーの振動として記述できる：

```
核子の運動エネルギー ↔ 格子線エネルギーの振動成分
核子の回転            ↔ 格子線の回転（スピン）
核の変形（変形核）     ↔ 格子の非対称振動
```

## 6. 格子の方向性と化学反応の解析

### 方向性を持つ力の項

3要素の法則の関係項 F_R は、もともと角度依存 f(θ,φ) を含んでいる：

```
F_R = G_R · (E₁ + E₂) / r³ · f(θ,φ)
```

この f(θ,φ) を格子の対称性に対応させることで、結晶構造ごとの結合の方向性を記述できる。

### 格子対称性と反応活性

| 格子構造 | 対称性 | Ce（量の中心） | 反応の方向性 |
|---------|--------|--------------|------------|
| 立方晶 | 高 | 球対称に近い | 低（どの方向も等価） |
| 六方晶 | 中 | 軸方向に偏る | 中（特定の方向に優先） |
| 四面体 | 低 | 4方向に局在 | 高（特定の角度で反応） |
| 界面・欠陥 | 崩壊 | Ceが局在 | 最高（活性点になる） |

### 化学反応における格子方向性の役割

1. **反応座標**：反応が進む方向は、格子のどの軸に沿うかによって異なる
2. **活性化エネルギー**：格子の対称性が高いほど Ce が球対称に近づき、反応の方向性が減少する
3. **触媒作用**：格子の欠陥や界面で対称性が崩れる場所が、反応の活性点になる

## 7. 統一的原理のまとめ

### 核分裂・核融合・化学反応の共通構造

| 現象 | 変化すもの | 不変なもの | エネルギー放出の原因 |
|-----|-----------|----------|------------------|
| 核融合（H→He） | 陽子間距離 r の消失、拘束の統合 | 質 M（要素数） | 力が中和され、過剰エネルギーが放出 |
| 核分裂（U→2核） | 拘束構造の再配分（1つ→2つ） | 質 M（要素数） | 過剰拘束エネルギーの再配分 |
| 化学反応 | 電子雲の拘束構造の再配分 | 質 M（要素数） | より安定な格子構造への移行 |
| Fe/Niへの収束 | 拘束が最適化 | 質 M（要素数） | 拘束エネルギーの最小化 |

### 現代物理の誤認の全体像

```
現代物理:
  観測：核反応後の質量が減少しているように見える
  → 誤解釈：質量がエネルギーに変換された
  → 公式：E = Δm·c²

TUB-TMCC:
  観測：核反応後の質量が減少しているように見える
  → 正しい解釈：拘束構造が変化し、力が中和して観測方法が変わった
  → 実際：質 M は不変、量 ΔM は拘束強化で増加
  → エネルギー：中和・再配分された力のエネルギー放出
```

E = mc² は「質量とエネルギーの等価性」を示す観測的関係式であり、「質量がエネルギーに変換される」ことを証明するものではない。
