# C-C 結合の3要素解析

> 共有結合（sp³混成）（Covalent Bond）

---

## 基本データ

| 項目 | 値 |
|------|-----|
| 結合の種類 | 共有結合（sp³混成） |
| 結合次数 | 1 |
| 結合距離 | 1.54 Å |
| 結合エネルギー | 347 kJ/mol = 3.60 eV |
| 構造 | 四面体構造（ダイヤモンド）、sp³混成 |

---

## 3要素方程式による解析

### 方程式

```
F_total = (G_M·M₁M₂ + G_E·E₁E₂ + G_ME·(M₁E₂ + M₂E₁)) / r² + G_R·(E₁+E₂)/r³ · f(θ,φ)
```

### パラメータ

| パラメータ | C | C |
|-----------|--------|--------|
| 質（M） | 24,000 | 24,000 |
| 量（E） | 3,000 | 3,000 |

### 力の計算（相対値、G_M = G_E = G_ME = 1）

```
共有電子対の量：E_shared = 1 × 500 = 500

F_M = G_M × M₁ × M₂
    = 1 × 24,000 × 24,000
    = 5.76e+08

F_E = G_E × E_shared²
    = 1 × 500²
    = 2.50e+05

F_ME = G_ME × (M₁·E_shared + M₂·E_shared)
     = 1 × (24,000 + 24,000) × 500
     = 2.40e+07
```

### 力の比率

```
F_M : F_E : F_ME = 2304 : 1 : 96
```

**支配的な力：F_M（質的引力）**

### 総力（距離による減衰込み）

```
r = 1.54 Å = 1.540e-10 m

F_total = (F_M + F_E + F_ME) / r²
        = 2.53e+28
```

---

## 結合の特徴

### 特記事項

共有結合：d ≈ 0（CmとCeが重なる）F_Mが圧倒的に大きい（2304:1:96）。

### 構造・性質

炭素の単結合：sp³混成、四面体構造（ダイヤモンド）。C-C結合は有機化学の基礎。

---

## 比較・考察

C=C（614 kJ/mol）、C≡C（839 kJ/mol）と比較して単結合は弱い

---

## 結論

### 3要素方程式からの知見

1. **支配的な力**：F_M（質的引力）
2. **結合の強さ**：結合エネルギー 3.60 eV は、3要素方程式の総力 2.53e+28 と対応
3. **構造的决定要因**：四面体構造（ダイヤモンド）、sp³混成

---

## 未解決・次の課題
