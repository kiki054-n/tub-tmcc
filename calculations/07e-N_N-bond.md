# N-N 結合の3要素解析

> 共有結合（三重結合）（Covalent Bond (Triple)）

---

## 基本データ

| 項目 | 値 |
|------|-----|
| 結合の種類 | 共有結合（三重結合） |
| 結合次数 | 3 |
| 結合距離 | 1.098 Å |
| 結合エネルギー | 945 kJ/mol = 9.79 eV |
| 構造 | 直線構造、三重結合（1σ + 2π） |

---

## 3要素方程式による解析

### 方程式

```
F_total = (G_M·M₁M₂ + G_E·E₁E₂ + G_ME·(M₁E₂ + M₂E₁)) / r² + G_R·(E₁+E₂)/r³ · f(θ,φ)
```

### パラメータ

| パラメータ | N | N |
|-----------|--------|--------|
| 質（M） | 28,000 | 28,000 |
| 量（E） | 3,500 | 3,500 |

### 力の計算（相対値、G_M = G_E = G_ME = 1）

```
共有電子対の量：E_shared = 3 × 500 = 1500

F_M = G_M × M₁ × M₂
    = 1 × 28,000 × 28,000
    = 7.84e+08

F_E = G_E × E_shared²
    = 1 × 1500²
    = 2.25e+06

F_ME = G_ME × (M₁·E_shared + M₂·E_shared)
     = 1 × (28,000 + 28,000) × 1500
     = 8.40e+07
```

### 力の比率

```
F_M : F_E : F_ME = 348 : 1 : 37
```

**支配的な力：F_M（質的引力）**

### 総力（距離による減衰込み）

```
r = 1.098 Å = 1.098e-10 m

F_total = (F_M + F_E + F_ME) / r²
        = 7.22e+28
```

---

## 結合の特徴

### 特記事項

三重結合：E_sharedが3倍（1500）。F_Eが単結合の9倍。結合エネルギーが非常に大きい（945 kJ/mol）。

### 構造・性質

窒素分子（N₂）：三重結合（1σ + 2π）、非常に安定。大気中で78%を占める。

---

## 比較・考察

O=O（498 kJ/mol）よりも強い。N≡Nは非常に安定で反応性が低い。

---

## 結論

### 3要素方程式からの知見

1. **支配的な力**：F_M（質的引力）
2. **結合の強さ**：結合エネルギー 9.79 eV は、3要素方程式の総力 7.22e+28 と対応
3. **構造的决定要因**：直線構造、三重結合（1σ + 2π）
