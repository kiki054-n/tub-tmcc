# O-H 結合の3要素解析

> 共有結合（極性）（Polar Covalent Bond）

---

## 基本データ

| 項目 | 値 |
|------|-----|
| 結合の種類 | 共有結合（極性） |
| 結合次数 | 1 |
| 結合距離 | 0.958 Å |
| 結合エネルギー | 492 kJ/mol = 5.10 eV |
| 構造 | 極性結合、水素結合ドナー・アクセプター |

---

## 3要素方程式による解析

### 方程式

```
F_total = (G_M·M₁M₂ + G_E·E₁E₂ + G_ME·(M₁E₂ + M₂E₁)) / r² + G_R·(E₁+E₂)/r³ · f(θ,φ)
```

### パラメータ

| パラメータ | O | H |
|-----------|--------|--------|
| 質（M） | 32,000 | 2,000 |
| 量（E） | 4,000 | 500 |

### 力の計算（相対値、G_M = G_E = G_ME = 1）

```
共有電子対の量：E_shared = 1 × 500 = 500

F_M = G_M × M₁ × M₂
    = 1 × 32,000 × 2,000
    = 6.40e+07

F_E = G_E × E_shared²
    = 1 × 500²
    = 2.50e+05

F_ME = G_ME × (M₁·E_shared + M₂·E_shared)
     = 1 × (32,000 + 2,000) × 500
     = 1.70e+07
```

### 力の比率

```
F_M : F_E : F_ME = 256 : 1 : 68
```

**支配的な力：F_M（質的引力）**

### 総力（距離による減衰込み）

```
r = 0.958 Å = 9.580e-11 m

F_total = (F_M + F_E + F_ME) / r²
        = 8.85e+27
```

## 結合の特徴

### 特記事項

極性結合：Oの高い電気陰性度（3.44）により電子がOに偏る。d/r > 0（量の中心がO側にずれる）。

### 構造・性質

水酸基（O-H）：極性結合、水素結合の形成能力。水・有機化合物の基礎。

---

## 比較・考察

H-F（568 kJ/mol）より弱いが、H結合形成能力が高い

---

## 結論

### 3要素方程式からの知見

1. **支配的な力**：F_M（質的引力）
2. **結合の強さ**：結合エネルギー 5.10 eV は、3要素方程式の総力 8.85e+27 と対応
3. **構造的决定要因**：極性結合、水素結合ドナー・アクセプター
