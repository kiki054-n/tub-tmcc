# Li-Li 結合の3要素解析

> 金属結合（Metallic Bond）

---

## 基本データ

| 項目 | 値 |
|------|-----|
| 結合の種類 | 金属結合 |
| 結合次数 | 1 |
| 結合距離 | 3.039 Å |
| 結合エネルギー | 105 kJ/mol = 1.09 eV |
| 構造 | 体心立方構造（BCC）、配位数8 |

---

## 3要素方程式による解析

### 方程式

```
F_total = (G_M·M₁M₂ + G_E·E₁E₂ + G_ME·(M₁E₂ + M₂E₁)) / r² + G_R·(E₁+E₂)/r³ · f(θ,φ)
```

### パラメータ

| パラメータ | Li | Li |
|-----------|--------|--------|
| 質（M） | 14,000 | 14,000 |
| 量（E） | 1,500 | 1,500 |

### 力の計算（相対値、G_M = G_E = G_ME = 1）

```
共有電子対の量：E_shared = 1 × 500 = 500

F_M = G_M × M₁ × M₂
    = 1 × 14,000 × 14,000
    = 1.96e+08

F_E = G_E × E_shared²
    = 1 × 500²
    = 2.50e+05

F_ME = G_ME × (M₁·E_shared + M₂·E_shared)
     = 1 × (14,000 + 14,000) × 500
     = 1.40e+07
```

### 力の比率

```
F_M : F_E : F_ME = 784 : 1 : 56
```

**支配的な力：F_M（質的引力）**

### 総力（距離による減衰込み）

```
r = 3.039 Å = 3.039e-10 m

F_total = (F_M + F_E + F_ME) / r²
        = 2.28e+27
```

---

## 結合の特徴

### 特記事項

電子海モデル：価電子が非局在化し、全金属原子間を移動。F_Eが集団的に共鳴。

### 構造・性質

リチウム金属：体心立方構造（BCC）、電子海モデル。各Li原子が8近接原子と結合。

---

## 比較・考察

Na（1.0eV）、K（0.9eV）と比較してLiは軽くて強い結合

---

## 結論

### 3要素方程式からの知見

1. **支配的な力**：F_M（質的引力）
2. **結合の強さ**：結合エネルギー 1.09 eV は、3要素方程式の総力 2.28e+27 と対応
3. **構造的决定要因**：体心立方構造（BCC）、配位数8
