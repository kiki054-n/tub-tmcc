# F-F 結合の3要素解析

> 共有結合（弱い）（Weak Covalent Bond）

---

## 基本データ

| 項目 | 値 |
|------|-----|
| 結合の種類 | 共有結合（弱い） |
| 結合次数 | 1 |
| 結合距離 | 1.42 Å |
| 結合エネルギー | 158 kJ/mol = 1.64 eV |
| 構造 | 単結合、非共有電子対3対が各F原子に |

---

## 3要素方程式による解析

### 方程式

```
F_total = (G_M·M₁M₂ + G_E·E₁E₂ + G_ME·(M₁E₂ + M₂E₁)) / r² + G_R·(E₁+E₂)/r³ · f(θ,φ)
```

### パラメータ

| パラメータ | F | F |
|-----------|--------|--------|
| 質（M） | 38,000 | 38,000 |
| 量（E） | 4,500 | 4,500 |

### 力の計算（相対値、G_M = G_E = G_ME = 1）

```
共有電子対の量：E_shared = 1 × 500 = 500

F_M = G_M × M₁ × M₂
    = 1 × 38,000 × 38,000
    = 1.44e+09

F_E = G_E × E_shared²
    = 1 × 500²
    = 2.50e+05

F_ME = G_ME × (M₁·E_shared + M₂·E_shared)
     = 1 × (38,000 + 38,000) × 500
     = 3.80e+07
```

### 力の比率

```
F_M : F_E : F_ME = 5760 : 1 : 152
```

**支配的な力：F_M（質的引力）**

### 総力（距離による減衰込み）

```
r = 1.42 Å = 1.420e-10 m

F_total = (F_M + F_E + F_ME) / r²
        = 7.35e+28
```

---

## 結合の特徴

### 特記事項

非共有電子対の反発：F原子には6個の非共有電子（3対）。F-F結合では非共有電子対同士の反発が強く、結合が弱い。F_R（関係項）が結合を弱める方向に作用。

### 構造・性質

フッ素分子（F₂）：単結合、非共有電子対の反発により結合が弱い。F₂は非常に反応性が高い。

---

## 比較・考察

Cl-Cl（243 kJ/mol）より弱い。非共有電子対の反発が大きいため。

---

## 結論

### 3要素方程式からの知見

1. **支配的な力**：F_M（質的引力）
2. **結合の強さ**：結合エネルギー 1.64 eV は、3要素方程式の総力 7.35e+28 と対応
3. **構造的决定要因**：単結合、非共有電子対3対が各F原子に
