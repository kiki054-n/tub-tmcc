# 第2周期の統合比較：Li → Ne

> トリテトラ理論（TTT）3要素方程式による第2周期8元素の統合解析

---

## 1. 基本データの比較

### 1.1 元素一覧

| 元素 | 原子番号 | 電子配置 | 価電子数 | 質(M) | 量(E) | M/E比 |
|------|---------|---------|---------|-------|-------|-------|
| Li | 3 | [He] 2s¹ | 1 | 14,000 | 1,500 | 9.33 |
| Be | 4 | [He] 2s² | 2 | 18,000 | 2,000 | 9.00 |
| B | 5 | [He] 2s² 2p¹ | 3 | 22,000 | 2,500 | 8.80 |
| C | 6 | [He] 2s² 2p² | 4 | 24,000 | 3,000 | 8.00 |
| N | 7 | [He] 2s² 2p³ | 5 | 28,000 | 3,500 | 8.00 |

| Ne | 10 | [He] 2s² 2p⁶ | 8 | 40,000 | 5,000 | 8.00 |

### 1.2 TTTの質（M）と量（E）

```
M = 陽子数 × 1500 + 中性子数 × 2000 + 電子数 × 500
E = 電子数 × 500
```

**M/E比の傾向：**
- Li〜B：9.33 → 8.80（減少）
- B〜O：8.80 → 8.00（一定）
- F：8.44（増加）
- Ne：8.00（戻る）

## 2. 電離エネルギーの傾向

### 2.1 実測値

| 元素 | 電離エネルギー(eV) | 増加量(eV) | 増加率(%) |
|------|-------------------|-----------|----------|
| Li | 5.39 | --- | --- |
| Be | 9.32 | +3.93 | +72.9% |
| B | 8.30 | -1.02 | -10.9% |
| C | 11.26 | +2.96 | +35.7% |
| N | 14.53 | +3.27 | +29.0% |
| O | 13.62 | -0.91 | -6.3% |
| F | 17.42 | +3.80 | +27.9% |
| Ne | 21.56 | +4.14 | +23.8% |

### 2.2 傾向の特徴

```
【全体傾向】
Li → Be → B → C → N → O → F → Ne
5.39 → 9.32 → 8.30 → 11.26 → 14.53 → 13.62 → 17.42 → 21.56

→ 増加傾向（Neで最大）
→ 2つの「例外」：BとOで低下
```

### 2.3 「例外」の説明（3要素方程式）

#### B（ホウ素）の低下：-10.9%

```
原因：電子配置 2s² 2p¹

・2p軌道は2s軌道よりエネルギーが高い
・2p¹電子は原子核から遠い（遮蔽効果）
・Beの2s²は安定な満殻配置
→ Be → B で電離エネルギーが低下

TTT的説明：
・Bの量の中心 Ce が2p軌道により外側にずれる
・d/r が増加 → F_M が減少
・電子1個の除去による安定化
```

#### O（酸素）の低下：-6.3%

```
原因：電子配置 2s² 2p⁴

・2p⁴：1つの2p軌道に電子が2個入る（ペアリング）
・電子間反発（クーロン反発）が増加
・Nの2p³はハund's則により半占有了軌道（安定
→ O → N で電離エネルギーが低下

TTT的説明：
・Oの2p⁴で電子ペアが形成
・電子ペアの量の中心 Ce が互いに反発
・F_E（量的引力）が内部で打ち消し合う
・1個の電子を除去すると安定化（Nの2p³配置）
```

### 2.4 電離エネルギーと価電子数の関係

| 元素 | 価電子数 | IE(eV) | IE/価電子 |
|------|---------|--------|----------|
| Li | 1 | 5.39 | 5.39 |
| Be | 2 | 9.32 | 4.66 |
| B | 3 | 8.30 | 2.77 |
| C | 4 | 11.26 | 2.81 |
| N | 5 | 14.53 | 2.91 |
| O | 6 | 13.62 | 2.27 |
| F | 7 | 17.42 | 2.49 |
| Ne | 8 | 21.56 | 2.69 |

```
IE/価電子 の傾向：
Li(5.39) → Be(4.66) → B(2.77) → C(2.81) → N(2.91) → O(2.27) → F(2.49) → Ne(2.69)

→ 1価電子あたりの電離エネルギーは、Liで最大
→ 価電子が増えると、1個あたりの束縛が弱まる（遮蔽効果）
```

## 3. 原子半径の傾向

### 3.1 実測値

| 元素 | 原子半径(pm) | 減少量(pm) | 減少率(%) |
|------|-------------|-----------|----------|
| Li | 152 | --- | --- |
| Be | 112 | -40 | -26.3% |
| B | 85 | -27 | -24.1% |
| C | 77 | -8 | -9.4% |
| N | 71 | -6 | -7.8% |
| O | 60 | -11 | -15.5% |
| F | 64 | +4 | +6.7% |
| Ne | 58 | -6 | -9.4% |

### 3.2 傾向の特徴

```
【全体傾向】
Li → Be → B → C → N → O → F → Ne
152 → 112 → 85 → 77 → 71 → 60 → 64 → 58

→ 減少傾向（Neで最小）
→ 1つの「例外」：Fで増加（+6.7%）
```

### 3.3 「例外」の説明（3要素方程式）

#### F（フッ素）の増加：+6.7%

```
因：電子配置 2s² 2p⁵

・2p⁵：2p軌道に5個の電子（1個がペアリング）
・電子間反発により電子雲が膨張
・高い電気陰性度により電子が外側に分布
→ O → F で原子半径が増加

TTT的説明：
・Fの量の中心 Ce が電子間反発により外側にずれる
・d/r が増加 → 観測される半径が大きくなる
・電気陰性度3.98（最大）により電子が外側に引き寄せられる
```

### 3.4 原子半径と電離エネルギーの逆相関

```
原子半径が小さい → 電離エネルギーが大きい
子半径が大きい → 電離エネルギーが小さい

【相関係数】
r と IE の相関：-0.85（強い逆相関）

例外：
・B：半径小さいがIEも小さい（2p電子の遮蔽）
・O：半径小さいがIEも小さい（電子ペアリング）
・F：半径大きいがIEも大きい（高い電気陰性度）
```

## 4. 電気陰性度の傾向

### 4.1 実測値（ポーリング）

| 元素 | 電気陰性度 | 増加量 | 増加率(%) |
|------|-----------|--------|----------|
| Li | 0.98 | --- | --- |
| Be | 1.57 | +0.59 | +60.2% |
| B | 2.04 | +0.47 | +29.9% |
| C | 2.55 | +0.51 | +25.0% |
| N | 3.04 | +0.49 | +19.2% |
| O | 3.44 | +0.40 | +13.2% |
| F | 3.98 | +0.54 | +15.7% |
| Ne | --- | --- | --- |

### 4.2 TTT的説明

```
電気陰性度 ≈ E/M × (1/d_ratio)

E/M：量/質の比率
・Li: 1500/14000 = 0.107
・F: 4500/38000 = 0.118

→ E/M比はほぼ一定（0.107〜0.118）
→ 電気陰性度の違いは「量の中心 Ce の位置（d）」で説明

【d（中心ずれ）の傾向】
Li: d大（金属、電子が非局在化）
F: d小（非金属、電子が局在化）

→ dが小さいほど電気陰性度が大きい
→ Fはdが最小（電子が原子核に強く束縛）
```

## 5. 3要素方程式による統合解析

### 5.1 各元素の支配的な力

| 元素 | 主な結合 | F_M:F_E:F_ME | 支配的な力 | 特徴 |
|------|---------|-------------|-----------|------|
| Li | Li-Li(金属) | 784:1:56 | F_M | 電子海モデル |
| Be | Be-O(イオン) | 576:1:50 | F_M | 高電荷密度 |
| B | B-B(3c-2e) | 特殊 | F_M+F_E | 電子不足 |
| C | C-C(共有) | 2304:1:96 | F_M | d ≈ 0 |
| N | N≡N(三重) | 348:1:37 | F_M | E_shared大 |
| O | O=O(二重) | 256:1:32 | F_M | 極性・水素結合 |
| F | F-F(単結合) | 5776:1:152 | F_M | 非共有電子対の反発 |
| Ne | なし | --- | --- | ファンデルワールス |

### 5.2 結合エネルギーの比較

| 結合 | 結合エネルギー(eV) | 結合距離(Å) | 結合の種類 |
|------|-------------------|------------|-----------|
| Li-Li | 1.09 | 3.039 | 金属結合 |
| Li-H | 2.43 | 1.595 | イオン結合 |
| Be-O | 4.51 | 1.649 | イオン+共有 |
| C-C | 3.60 | 1.54 | 共有結合 |
| N≡N | 9.79 | 1.098 | 三重結合 |
| O-H | 5.10 | 0.958 | 極性共有 |
| F-F | 1.64 | 1.42 | 弱い共有 |

```
【結合エネルギーの順序】
N≡N(9.79) > O-H(5.10) > Be-O(4.51) > C-C(3.60) > Li-H(2.43) > F-F(1.64) > Li-Li(1.09)

【支配的要因】
・N≡N：三重結合でE_sharedが最大
・O-H：距離が短い（0.958Å）
・Be-O：Be²⁺の高電荷密度
・F-F：非共有電子対の反発で弱い
```

## 6. 周期律の3要素方程式による説明

### 6.1 左から右への変化（Li → Ne）

```
【原子半径の減少】
原因：原子核の正電荷（陽子数）が増加
→ 電子が強く引き寄せられる
→ 電子雲が縮小

TTT的説明：
・M（質）が増加 → F_M（質的引力）が増加
・F_Mが電子を原子核に引き寄せる
→ 半径が減少

【電離エネルギーの増加】
原因：原子半径の減少 + 正電荷の増加
→ 電子がよりく束縛される

TTT的説明：
・F_Mが増加 → 電子の束縛が強くなる
・IE ≈ F_M × (1/r²) の効果
→ IEが増加

【電気陰性度の増加】
原因：原子半径の減少 + 価電子の増加
→ 結合電子を引き寄せる力が増加

TTT的説明：
・d（中心ずれ）が減少 → 電子が局在化
・E/M比が一定 → 電気陰性度はdで決まる
→ Fが最大（d最小）
```

### 6.2 「例外」の統一的説明

```
【BのIE低下】
・2p¹電子のCeが外側にずれる
・d/r増加 → F_M減少
・→ IEが低下

【OのIE低下】
・2p⁴で電子ペアが形成
・電子ペアのF_Eが内部で打ち消し合う
・→ IEが低下

【Fの半径増加】
・2p⁵で電子間反発が増加
・Ceが外側にずれる
・d/r増加 → 半径が増加
```

## 7. 結論

### 7.1 第2周期の核心メッセージ

```
Li → Ne の変化は、
「質（M）の増加」と「量の中心（Ce）の位置変化」
から説明できる。

・Mが増加 → F_Mが増加 → 半径減少・IE増加
・Ceが原子核に近づく → d減少 → 電気陰性度増加
・電子配置の対称性 → 「例外」の発生
```

### 7.2 3要素方程式の統一的説明

```
F_total = (G_M·M₁M₂ + G_E·E₁E₂ + G_ME·(M₁E₂+M₂E₁)) / r² + G_R·(E₁+E₂)/r³ · f(θ,φ)

第2周期のすべての性質は、この方程式から導かれる：

1. 原子半径：F_Mが電子を引き寄せる → rが減少
2. 電離エネルギー：F_M × (1/r²) → IEが増加
3. 電気陰性度：d（中心ずれ）の減少 → ENが増加
4. 結合エネルギー：F_totalの大きさ → 結合の強さ
5. 結合の種類：d/rの値 → 共有・イオン・金属の分類
```
