## TTTの質と量

### 質（要素数）

```
M = 陽子数 × 1500 + 中性子数 × 2000 + 電子数 × 500
  = 7 × 1500 + 7 × 2000 + 7 × 500
  = 10500 + 14000 + 3500
  = 28000
```

### 量（格子線エネルギー）

```
E = 電子数 × 500
  = 7 × 500
  = 3500
```

### 質量比

```
M / M_H = 28000 / 2000 = 14.0
E / E_H = 3500 / 500 = 7.0
```

## 3要素解析

### 質の中心（Cm）

窒素の原子核（陽子+中性子）の質量分布の重心。

### 量の中心（Ce）

5個の価電子の格子線エネルギー分布の重心。

### 中心ずれ（d）

```
・価電子の配置により Ce が Cm からずれる
・d/r の値が結合の種類を決定する
```

---

## 結合特性

### 主な結合の種類

共有結合（三重結合N≡N）、孤立電子対

### 特徴

非金属、気体（N₂）、三重結合で非常に安定、非共有電子対1対

---

## 物質状態

### 常温常圧での状態

気体

### 3相の3要素方程式による説明

```
固体：3つの力（F_M, F_E, F_ME）が強く釣り合う
液体：3つの力が揺らぐ（温度振動）
気体：3つの力が弱い（分子間距離が大きい）
```

---

## 周期律表での位置

### 第2周期の傾向

```
Li → Be → B → C → N → O → F → Ne
金属性減少 → 非金属性増加 → 希ガス
電離エネルギー増加（全体傾向）
電気陰性度増加
原子半径減少
```

### 隣接元素との比較

左隣: C
右隣: O
